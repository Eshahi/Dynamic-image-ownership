- [x] Reviewer differs from author.
- [x] Exact reviewed analysis SHA recorded; relevant contracts and immutable A5 hash recorded.
- [x] Mathematical claims manually checked with assumptions and scope.
- [x] Proposal method excerpt checked; original DOCX/figures not newly verified.
- [x] No experiment results inferred from analytical equations.
- [x] Detector/evaluator information separated; key drift and encoded output failures retained as obligations.
- [x] Required audit helper contract inspected; manual audit identified honestly, no forged manifests.
- [x] Windows Unicode print failure recorded and recovered with -X utf8.
- [ ] Pinned model/code/license and differentiable initial-noise path (future A5 work).
- [ ] Exact algorithm/schema and resource estimate (future A5/A6 work).
- [ ] Calibration/splits/independent units/run inventory and stopping (future A4 work).
- [ ] Scientific execution manifest and user approval (not requested or granted).
- [ ] Dataset/input hashes, executed seeds/output hashes and empirical reproducibility (not applicable to current unexecuted analysis).

Unchecked downstream entries are not blockers to accepting honest partial analysis. They block the corresponding stronger architecture/execution/results claims.
