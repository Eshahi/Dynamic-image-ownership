# C4 bounded mechanism pilot

The canonical JSON experiment-spec.yaml applies research/research-contract.md and research/scope-guard.md. It is exploratory, prospective before C4 learned-model output, not a confirmatory watermark study. Unit: one locked native source/trial; two updates and matched control are dependent observations. No population power/CI/FPR analysis is meaningful here.

1. Preview-only prepare_c4_execution.py requires clean tracked checkout, pins all transitive code/config/source metadata/design/environment bytes and writes an exclusive manifest outside the checkout. Official experiment-design helper validates/packages the spec and execution; official compute runner previews the exact canonical manifest hash. Neither authorizes science.
2. Independent actor reviews exact artifacts/commit/package. Ask the user for exact local run/hash/20-minute/zero-dollar approval; only official runner validates/consumes it. Do not create approval by inference from download/software approvals.
3. Runner starts reviewed Windows parent; full C1 validation binds the exact non-calibrated config to a typed Linux receipt. Linux rechecks all input hashes, frozen source/linked groups and interpreter/all62 distribution versions before model imports. Version metadata is not package payload attestation; A6 offline wheel rebuild evidence and pinned CLIP source remain prerequisites.
4. Fixed source byte/canonical/dimension checks and resource headroom precede model load. Snapshot existing verified SD assets privately (2,742,217,630 bytes), enroll with existing pinned CLIP CUDA float32 then release encoder. SD float32 gradient fit is unknown; do not substitute smaller model/dtype/source if it fails.
5. Persist trial before models, keep gradients/u/continuous enrollment-informed scores and final update. Save matched control and marked RGB8 PNGs, roundtrip actual saved pixels, safety-check both. No threshold/blind detector or quality metrics are included. Source and diagnostics remain local restricted academic artifacts; no redistribution/rights certification.
6. Preserve all errors and pending phases; no retry. Official runner hashes its three declared report/journal outputs. Additional fsynced trial trajectory, PNGs and model/source snapshots remain under the same local run directory; TrialStore records PNG/pixel identities. Their retention is not an independent remote backup. Missing terminal JSON on timeout must be reported missing, not converted to success.

Fixed budgets and limits are in compute-estimate.json and the canonical manifest. External asset/image identities are bound through frozen-case/A6 inventory and checked by the reviewed worker, not arbitrary absolute-path manifest inputs. Canonical manifest must not be committed into its own input inventory. No lifecycle gate or C4 issue is advanced on this package alone.
