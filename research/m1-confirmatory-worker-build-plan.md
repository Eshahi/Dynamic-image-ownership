Its fixture worker generates JSON tokens. It rejects scientific datasets and non-rehearsal inputs before reading them. Do not relax that rejection or call its tokens scientific observations. Build a separate scientific launcher/worker, retaining the synthetic fixture harness.

The Windows helper creates a suspended owned child, assigns/verifies its private kill-on-close Job, persists ownership, then resumes. Reuse this ordering for every real worker; no scientific code may execute before assignment. Existing tests establish containment primitives, not candidate-specific GPU/image lifecycle rehearsals. Official dispatcher passes only `--manifest FILE --output-dir DIR`, uses its own interpreter and creates a fresh artifact destination. Existing development manifests, fixed IDs and hardcoded MAIN paths are not official adapters.

## External raw manifest and unlock responsibilities

Preparation may copy **already existing** admitted raw/annotation receipt metadata into the contained index after the source-contract process identifies the authoritative records; it must not hash/decode held-out bytes, inspect annotations or compute features to fill gaps. Missing exact receipts are a package blocker to resolve from acquisition provenance, not permission to open data early. Record index producer, admitted source-manifest hash, schedule hash, exact annotation artifact receipt/release/license and preprocessing implementation hash. Existing acquisition supplies an extracted instances_val2017.json hash/size; original ZIP hash/revision remain unavailable. The extracted artifact can be prospectively frozen as the annotation input without inventing archive identity; see m1-confirmatory-external-index.md. Absolute host roots belong in a reviewed resolver contract, not arbitrary CLI overrides. The official manifest lists the contained index as `{path,sha256}`; its external file members are verified by the worker only after unlock.

Scientific unlock belongs to the official dispatcher with the user's exact milestone approval and applicable real source/scope decisions. Agents do not create an approval or gate JSON. A config boolean is not authorization. The standalone internal child must require a reviewed launch envelope/capability and verify exact canonical execution-manifest digest, authorized dataset/schedule/index/core and owned output destination before raw I/O. The launcher must establish a concrete fail-closed capability mechanism under the official interface; this is new core infrastructure work, not implemented by the current harness. Preflight schema/hash checks must not follow external image paths. Synthetic rehearsal uses generated images through the same adapter interface and cannot unlock scientific paths.
