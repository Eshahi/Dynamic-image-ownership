# B2 model-free candidate-search boundary

Status 2026-09-24: **bounded arithmetic/control reference, not a blind or runnable detector**. Issue #9 / draft PR #57. This applies the [A5 method specification](method-spec.md), [research contract](research-contract.md) and [scope guard](scope-guard.md) to the direct-DCT comparator's eventual verifier path.

`scripts/candidate_search_reference.py` enumerates the suspect's exact code and radius-one bit flips in low-bit order. For canonical 12-bit `q(J)` and 32-bit `H_p(J)`, this is 13 semantic and 33 pHash candidates, or 429 q/h instance pairs per tested OwnerID. It invokes caller-supplied score callbacks exactly once per candidate and retains each bounded score/veto/hit in deterministic order. The callback must return a finite score in `[-1,1]` and a Boolean zero-variance flag. A hit requires **strictly greater** than its frozen threshold and no zero-variance veto, even if a negative threshold would otherwise make a zero score appear positive.

The common-q rule is enforced explicitly: `both_match` is true only if a semantic hit and an instance hit share one q candidate. A synthetic vector with semantic hit at the original q and instance hit at its bit-0 neighbor returns `semantic_hit=true`, `instance_hit=true`, `cross_q_only=true`, `both_match=false`. This exposes a diagnostic gap in A5's four named component states: two component hits on different q candidates fit none of `semantic_only`, `instance_only`, `both_match`, or `neither_match` without mislabeling. The reference adds **a diagnostic flag, not a new official detector state or a positive match**. C5 implementation/review must settle how to serialize that non-joint state before a locked scientific run; do not quietly call it `both_match` or choose the favorable component.

The follow-up `evaluate_pixel_control_candidates` in `scripts/pixel_dct_control.py` now accepts **supplied suspect q/H codes** and canonical RGB8 bytes, computes both component DCT observations once per image block, derives public OwnerID keys/templates for the complete search, and applies caller-supplied thresholds through the bounded reference. A synthetic 32×32 RGB8 marked vector with supplied q/H and a test config ID gave a joint candidate at the original q/H; an instrumented test counted exactly 16 image-block DCT calls, not 16×442. This test supplies codes that happen to reproduce the source signature; it does **not** extract q/H from the marked image, establish signature stability, or constitute blind verification. The two component template streams remain separate.

All 43 B2-branch script tests pass, including search order/count, common-q counterexample, strict threshold, veto, malformed/nonfinite input, synthetic component scores and the one-DCT-per-block integration vector. This code does not validate a complete A5 configuration or enrollment, load CLIP, decode PNG, pin image/color libraries, guarantee a frozen threshold, authorize a model/dataset download, or run a comparator on study data. It is not a full-verification latency measurement. The full detector must preserve all candidate/failure provenance and settle the cross-q diagnostic status before scientific use; B2 remains open.
