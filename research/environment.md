## Scientific runtime not yet locked

The A5 architecture pins official `openai/CLIP` source commit `d05afc436d78f1c48dc0dbf8e5980a9d471f35f6`, with an expected ViT-B/32 checkpoint digest, and Diffusers `v0.35.1` commit `0f252be0ed42006c125ef4429156cb13ae6c1d60`. Its proposed Stable Diffusion 1.5 model is an unaffiliated mirror revision whose weight identity, rights and equivalence remain unresolved. The CLIP checkpoint was not downloaded. Official [CLIP requirements](https://github.com/openai/CLIP/blob/d05afc436d78f1c48dc0dbf8e5980a9d471f35f6/requirements.txt) include PyTorch, TorchVision, ftfy, regex and tqdm. [Diffusers installation guidance](https://huggingface.co/docs/diffusers/v0.35.1/en/installation) requires a compatible PyTorch environment and recommends isolation. The tiny Stage-1 GPU pass does not establish that Diffusers, CLIP or the proposed model work on this stack.

The A4 quality profile also needs a **two-weight LPIPS runtime**, not just the `lpips` package. Pinned [upstream LPIPS source](https://github.com/richzhang/PerceptualSimilarity/blob/082bb24f84c091ea94de2867d34c4544f68e0963/lpips/lpips.py) loads the `v0.1/alex.pth` learned linear weights and calls the [TorchVision-pretrained AlexNet feature trunk](https://github.com/richzhang/PerceptualSimilarity/blob/082bb24f84c091ea94de2867d34c4544f68e0963/lpips/pretrained_networks.py). GitHub's content API at that LPIPS commit reports `lpips/weights/v0.1/alex.pth` as a 6,009-byte Git blob `1df9dfe62abb1fc89cc7f82b4e5fe886c979708e`; this is **not** a local SHA-256 receipt. Candidate [TorchVision v0.27.1 source](https://github.com/pytorch/vision/blob/v0.27.1/torchvision/models/alexnet.py) names the ImageNet-1K V1 trunk URL `alexnet-owt-7be5be79.pth`; the filename embeds only a hash prefix. Its [documented minimum input size is 63×63](https://docs.pytorch.org/vision/master/models/generated/torchvision.models.alexnet.html), while A5 accepts 32×32 inputs. Before scientific use, pin exact LPIPS/TorchVision package builds, acquire both weights through approved sources, verify full SHA-256 and terms, disable implicit model downloads, and test the native-resolution 63-pixel boundary and numerical parity. Sub-63 source images cannot silently be upscaled for LPIPS. No LPIPS/AlexNet weights or packages were downloaded or executed for this preflight.
