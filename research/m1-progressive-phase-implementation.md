The manifest fixes four original prompt/seed clusters, C0 replay, early alpha.5/eta100 replay, late alpha.5/eta100, and late complementary target: 16 generations / 800 CFG-batched U-Net calls / 32 clean+additional-VAE conditions. Only the guidance interval changes between early/late arms. Extraction bits/mask and all64 fixed SHAKE hypotheses remain reference independent.

Before model loading, the runner requires committed code/manifest/dependencies through Git's CRLF-aware `hash-object --path`, verifies original0031 run/script and all16 replay PNG receipts, copies the manifest, and writes provenance. Hash comparison reads original PNG bytes without rewriting them. Old-C0 pixels are read only inside the authorized synthetic scientific run for explicitly labelled old-vs-new generated-counterfactual quality. No existing/held-out photo is accessed.

Per generation, initial/final scaled latent arrays, decoded float array, clipped decoded array and float-cycle latent are saved as non-pickle NPY with file/raw hashes, shapes and dtypes. All50 trace rows flush immediately. Each row names ordinary/corrected/effective-fp16 predicted-clean coefficients separately from the actual noisy scheduler output, retaining128 coefficients, decoded word, target MSE and sign counts; gradient/correction norms, changed-entry counts, zeros/nonfinites, dtype, q_t and same-state local DDIM displacement are retained. The local unmarked comparator is stateless eta0 DDIM arithmetic using the same current state/original epsilon, without extra U-Net inference. Synthetic CPU replay tests compare the instrumented trajectories bit-for-bit with literal old arithmetic.

Endpoint stages are terminal_predecode, clipped_float_cycle, clean_rgb8 and additional_vae_rgb8. The first two are labelled ineligible image-detector diagnostics. Ordinary primary condition scoring retains the existing image-DCT diagnostic and native VAE-DCT readout plus synchronized timings. Hash mismatch preserves the output but makes replay attribution fail. The late carrier/C0-negative and quality gates are separate; scientific necessary-condition/quality attribution is null when replay fails or inventory is incomplete. Oracle readouts never count as extra image successes.

Atomic `run.json` and `conditions.json` checkpoints preserve all16/32 planned units even before model load. `rows.jsonl` flushes started/completed generation and completed condition events; partial trace files receive a final hash on interruption/failure. Exceptions and KeyboardInterrupt finalize failed/interrupted receipts and missing inventories. A stopped attempt is immutable history: retry in a fresh directory, no automatic resume/overwrite/best-attempt merge. This <=300-s diagnostic does not require a long-run resumable implementation.

These limits are guards, not measured runtime guarantees. Traces add synchronization and extra diagnostic VAE encodes, so previous172-s/28-generation time is only an estimate.
