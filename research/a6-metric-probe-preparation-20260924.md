# A6 metric parity probe preparation

Status 2026-09-24: **implementation and synthetic tests only; pretrained metric mode was not run**. Issue #7 / draft PR #58. The separately asked question about one bounded CLIP and LPIPS/AlexNet load with fixed synthetic CPU/CUDA measurements is still pending. This document and the new script do not grant or infer that approval.

`scripts/check_a6_metric_parity.py` defaults to an offline byte-only path: it requires the exact 17-file candidate asset-lock digest, verifies every declared asset size/SHA-256, and checks four installed LPIPS package files including the learned layer. It then exits with `verified_no_model_load`. The explicit `--load-metrics` mode is reserved for a future affirmative user reply and an external maximum-20-minute process timeout. No such invocation occurred here.

The reserved mode blocks socket connections, requires launch-time `CUBLAS_WORKSPACE_CONFIG=:4096:8` and `PYTHONHASHSEED=0`, and enables strict Torch determinism. It refuses CLIP's fallback pickle path by requiring the pinned local checkpoint to load as a JIT archive, then reconstructs the official ViT-B/32 model for a fixed 224×224 generated RGB8 input. It requires a finite nonzero 512-vector and reports CPU/CUDA float32 fingerprints, normalized maximum absolute difference and cosine similarity. It neither accesses a study image nor runs diffusion or a thesis detector.

The LPIPS path creates an AlexNet architecture with `weights=None` and an LPIPS wrapper with `pnet_rand=True, pretrained=False`, so no constructor may fetch weights. It then loads the separately verified local AlexNet trunk and five learned LPIPS layers with `torch.load(weights_only=True)`, checking the state dictionaries before scoring one fixed 64×64 synthetic RGB8 pair under no-grad on CPU and CUDA. It reports the two scalar distances and difference, not a quality pass or a 63-pixel boundary acceptance. The implementation has not yet been exercised with real checkpoints; any loader/key mismatch must be recorded as a failed preflight, not silently bypassed.

Three new model-free tests cover the fixed synthetic bytes, fail-closed asset identity and launch setting guards. The full repository script suite found **68 tests: 66 passed, two expected skips**. Syntax compilation also passed. This does not verify actual CLIP/LPIPS loadability, CPU/CUDA parity, production preprocessing or the full A5 method.
