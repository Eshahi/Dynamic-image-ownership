## Design method, precision and FPR resolution

This is **fixed-N precision planning**, not a pilot-derived power calculation. For a binomial within-condition rate, use a two-sided 95% Wilson interval; worst-case width occurs near `p=0.5`. The table lists its half-width at `p=0.5` and the one-sided 95% exact upper bound after **zero** false matches, `1−0.05^(1/n)`, valid only for independent negative source groups and a threshold frozen on disjoint data. Values are percentages, rounded to three decimals. Computation: Python standard-library `NormalDist().inv_cdf(0.975)` for Wilson; `ceil(log(0.05)/log(0.99))=299` independent negatives are required for zero-FP upper bound ≤1%. Formula conventions were cross-checked against the [NIST binomial proportion interval reference](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/propconf.htm).

| ---: | ---: | ---: | --- |
| 100 | 9.617% | 2.951% | Insufficient to resolve 1% with zero FP |
| 200 | 6.864% | 1.487% | Proposed COCO validation count cannot *infer* 1% |
| 300 | 5.622% | 0.994% | Minimum planned domain test; any FP may prevent 1% claim |
| 600 | 3.988% | 0.498% | Proposed COCO locked test |
| 1,000 | 3.093% | 0.299% | One source-domain validation size, but calibration is biased |
| 3,000 | 1.788% | 0.100% | Proposed DiffusionDB locked test |
| 5,000 | 1.385% | 0.060% | Full generated subset, **not** all locked test |

Independent n=300 yields at best about ±5.62 percentage points worst-case two-sided 95% precision; it does **not** meet ±5 points. At n=300 and one false positive the one-sided exact upper bound is **1.571%**, exceeding 1%. The 1% operating target is therefore ambitious and sensitive to a single error on DIV2K test. A lower threshold does not cure uncertainty. Validation n=200 for COCO can select a threshold by an explicitly declared empirical rule, but cannot support an unbiased 1% FPR inference from that same sample. All inferential bounds come from locked test. If content dependence, a missing/ineligible source group, or invalid grouping reduces the count of **independent eligible source groups** below 299, explicitly mark that cell **insufficient resolution** rather than pooling domains or counting transforms/seeds as new images. A failed output from an otherwise eligible group stays in the primary denominator and is counted adversely as specified below; it does not reduce independent n. Bootstrap resampling estimates variability of the observed independent units; it creates no new independent negatives.

For primary C1 TPR and each C0/C2 FPR, calculate exact one-sided 95% bounds for the draft joint objective and also report two-sided Wilson intervals and raw x/n by domain. Distinguish source C0 from matched-reconstruction C0. Domain pooling may be described with transparent weights but does not replace domain-specific criteria. The frozen conservative failure convention in `acceptance.md` treats invalid/missing/timeout C1 as a miss and invalid/missing/timeout negative-condition outputs as false matches **for the primary FPR bound and validation threshold eligibility**, while reporting actual observed-valid FPR and technical failures separately. This is a worst-case accounting convention, not an assertion that an unavailable negative output matched. The denominator is the predeclared eligible independent source-group count, subject to later B3/B4 provenance and grouping review; no extra seeds or attacks may increase it. Do not claim 1% if unresolved outcomes or a reduced independent count prevent it.

## Paired comparisons, effects, seeds and confidence

RQ1 combined/semantic/pHash comparisons and RQ2 latent/pixel survival use the same source IDs when both methods are available. Their relevant variance is the **paired discordance**, not two independent-proportion formulas. With no pilot estimate, a **single defensible** minimum detectable paired effect or power claim cannot be asserted from the data; prospective sensitivity calculations over explicitly assumed discordance values are possible and required before confirmatory comparison. Freeze comparator implementations, practical effect/margin, assumed paired-discordance sensitivity grid, desired power, and familywise error strategy before test. If fixed N cannot detect a defensible effect, report the actual interval and label the hypothesis inconclusive. Use source-group cluster resampling for correlated seeds/attacks/pairs; independent seeds measure algorithmic variability, not extra source-image N. The primary profile now specifies one deterministic seed per source by the published `a4-seed-v1` schedule in `acceptance.md`; actual seed values await B3/B4 source IDs. A separate fixed multi-seed sensitivity set is `BLOCKED_PROTOCOL`. Failed seeds stay in inventory. Runtime measurements use repeated timed calls **nested within source/hardware run**, reporting median/quantiles and paired source-level differences, not treating milliseconds or DCT blocks as independent samples.

Wilson half-width target ±0.06 at worst-case p=.5 first becomes attainable at **n=263** independent units; thus n=300 supports that precision on valid independent outcomes, while ±0.05 first needs **n=381**. These are precision—not power—calculations. Proposed FPR target 1%, positive TPR floor 80%, per-domain rule and split allocation are explicit draft technical choices, **not** approved proposal numbers. No noninferiority margin is currently justified for RQ3/HYP3; a nonsignificant difference is not equivalence. The source proposal's quality thresholds PSNR >35 dB, SSIM >0.9 and LPIPS <0.1 are separate targets; no sample-size calculation turns them into achieved results.
