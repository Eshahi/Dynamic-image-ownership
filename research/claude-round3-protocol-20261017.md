## 1. Definition of a "different image" (for the supervisor)

The verification is asked to accept images derived from the enrolled image by regeneration (the attack), and to reject other images. Some real look-alikes are as close to the original as a regenerated copy is. Example: two video frames 3 s apart in a nearly still shot, 23-28 dB PSNR apart, while a strength-.2 regenerated copy is a median 24 dB from its original. No content-based check can be required to separate those.

**Primary definition.** A look-alike counts as a different image only if it differs from the enrolled image more than the attack does. Concretely, its grey PSNR to the enrolled image must be below the 5th percentile of the PSNR between strength-.2 regenerated copies and their originals. That is, it differs more than 95% of regenerated copies do.
- The cutoff is measured on the calibration data (both regenerators pooled) and then frozen.
- Look-alikes at or above the cutoff are "ambiguous recaptures". They are reported separately and neither count as false accepts nor set thresholds.

**Secondary definition, reported only.** The same rule with the median instead of the 5th percentile.

The distance is plain grey PSNR on the canonical 512 × 512 images (Pillow "L").

## 2. Verification rule (frozen before any new image exists)

- **D1:** E3's native fine-detail vector (cosine).
- **B1:** the 32 × 32 grey layout vector (box resize, mean-subtracted, cosine).
- **Main rule:** if D1 is available for both the query and the record, accept when D1 ≥ τ1 and B1 ≥ τ2.
- **Plain-image fallback:** if D1 abstains for either image (native weak-detail floor), accept when B1 ≥ τF.
- **Pointer:** registry acceptance (F_R) also needs the recovered F5 r2 pointer, exactly as in step 2. The method choice is unchanged.

## 3. Calibration (already-consulted data only)

**Calibration data:** all 60 step-2b sources (its 20 calibration and 40 evaluation sources), all 20 Tears of Steel pairs used so far, all T4 residual transfers from step 2b and the six synthetic siblings (seeds 1-6).

**Negatives used to set thresholds:** wrong-source pairs, T4 transfers, synthetic siblings and look-alikes classified "different" under the primary definition.

**Threshold search:**
- For τ2 on the grid {0.50, 0.51, …, 0.79} ∪ {0.800, 0.805, …, 0.995}:
  - τ1 = max(nextafter(max D1 over those negatives with B1 ≥ τ2), 0.0594367);
  - τF = max(τ2, nextafter(max B1 over those negatives in which D1 abstains for either image)).
- Score: C1 regenerated positives accepted by source majority (at least 2 of 3 seeds) at strength .2, summed over SD1.5 and SD2.1.
- Choose the highest score; ties go to the higher .4 sum, then to the larger τ2.
- Freeze (τ1, τ2, τF, PSNR cutoff) in a committed JSON before any round-3 image is generated.
