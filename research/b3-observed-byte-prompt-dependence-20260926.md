This integrates completed-image integrity with the already-reviewed private metadata eligibility ledger while the original authorized download writer continues. It is not final image selection, B4 split allocation, canonical preprocessing or scientific compute.

## Bound evidence and implementation

The [observed dependence helper](../scripts/b3_observed_dependence.py) requires the exact previously reviewed private eligibility artifact SHA-256 `8c465e630e299a57ab7979c358a5cff614e78923a4eeceee339fa363f2a38049`, and caller-declared exact digests of previously verified per-part image inventories. Same hash-checked snapshots are parsed, with regular/unlinked file checks and 16 MiB snapshot ceilings before allocation and after reading. Existing strict CSV schemas, 1,000-image complete-part cardinalities, qualified-ID uniqueness and raw-byte size/dimension consistency checks are reused. Only DiffusionDB part inventories are admitted; every observed identity must exist in its bound metadata part.

The join applies the recorded metadata eligibility reason but removes no source bytes or records. For eligible images it constructs private **connected components of shared raw-byte hash OR shared normalized exact-prompt group**. Both edge types are combined transitively, not counted independently. Raw and prompt hash namespaces are distinct. Sorted qualified identities make results permutation-independent. Component IDs bind current membership and can change when a later observed image bridges components; they are **not stable final split IDs**. No representative is chosen or 5,000-image source set frozen.

The existing reviewed CSVs, not arbitrary caller-provided digests, authenticate the evidence used here. This step does not re-read every original image byte; image integrity is proven only by its linked archive receipts. Prompt fingerprints and component members stay in ignored local artifacts: hashed prompt groups are not anonymized public data. Components cover eligible observed nodes only, and excluded records retain their reason counts. Nothing here certifies image content, licensing, decoded/canonical equivalence, near-duplicates, shared users or broad semantic dependence. B4 must later preserve relevant combined dependence and holdout requirements rather than assume these components prove independence.
