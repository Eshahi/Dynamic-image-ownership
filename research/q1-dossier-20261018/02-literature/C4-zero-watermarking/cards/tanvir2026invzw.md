- **Mechanism / access:** ViT features trained through clean/distorted adversarial discrimination, with reconstruction discouraging collapse. Image-associated reference and projection optimization associate an external message with features without editing pixels. Attacks are image distortions; malicious enrollment access is not established.
- **Detector information / payload:** Feature extractor, learned projection and reference matrix; original full image unnecessary, but the learned reference is detector side information. Comparisons use 30-bit messages.
- **Evaluation / numbers:** Feature training: 40,000 COCO images; reported feature test pools include 5,000 each COCO/Imagenette/Flickr30k and 900 DIV2K images. Do not assume these are the denominator of every watermark result: that mapping was not clear in inspected text. Geometric training and stronger geometric plus noise/color/JPEG tests. Table 6 gives 95.3% bit accuracy under Gaussian noise 0.10. Bit accuracy is not whole-message acceptance or owner-attribution TPR.
- **Limits / relevance:** No diffusion regeneration test identified. Demonstrates that learned robust features plus externally learned payload association predate this thesis framing. It does not establish resistance to competing-owner registration or same-shot look-alikes. The arbitrary decoded payload is external association, not evidence that its owner signal physically survived in the image.
