# Saberi et al. — DREW

- **Title:** DREW: Towards Robust Data Provenance by Leveraging Error-Controlled Watermarking.
- **Authors:** Mehrdad Saberi; Vinu Sankar Sadasivan; Arman Zarei; Hessam Mahdavifar; Soheil Feizi.
- **Year/venue/version:** 2024; arXiv preprint, 2406.02836v2, 20 June; no final venue verified.
- **URL/DOI:** https://arxiv.org/html/2406.02836v2 ; 10.48550/arXiv.2406.02836.
- **Access/verification:** 2026-10-18; V2, current method/evaluation reading, no reproduction.
- **Locators:** §3.3 Algorithms 1–2; §3.4; §§4.1–4.2; Table 1; §5; Appendix C.

**Direct evidence.** A watermark identifies a random database cluster; continuous embedding search chooses the record. Unreliable ECC decoding triggers whole-database retrieval. Side information comprises stored descriptors, cluster assignment, watermark/ECC decoders and retrieval threshold. Experiments use 100-bit marks, 10-bit cluster codes, 1,024 clusters, 768-dimensional DINOv2/CLIP embeddings, six datasets and 1,000 queries per dataset/modification. Table 1 Art Images/DINOv2, Diff .2: DREW and descriptor-only both .765; Crop .5: .991 versus .752. Diffusion purification is evaluated, so a first-hybrid-under-regeneration claim is untenable. Appendix C describes adversarial descriptor evasion and wrong-cluster spoofing; the latter remains future robustness work.

**Inference/relevance.** Direct architectural antecedent. Cluster routing differs from an owner-and-record pointer and conjunctive record verification. Retrieval improvements do not prove authenticity, ownership or security against competing enrollment. The Diff .2 setting is not established as identical to this thesis's DDIM protocol.
