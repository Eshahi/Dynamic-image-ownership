## Agent inference for the thesis, distinct from paper evidence

This small, access-selected set supports an evidence-design pattern: isolate a mechanism, compare relevant baselines at comparable distortion/payload, measure transfer to transformations withheld from training, and ablate the mechanism. It does **not** establish mandatory baseline counts, dataset sizes, page counts, theorem requirements, FPR levels or human-study requirements for TIFS. CA-QIM supplies a counterexample to treating every successful watermarking paper as a large learned-model benchmark.

IAP is particularly relevant to the registry direction: it already uses an embedded database pointer and comparison against an enrolled source. That conceptual pattern is not new by itself. Its reported protection-state FPR is a different event from wrong-owner attribution, copied-mark attribution, or acceptance of a semantically colliding image. Likewise StyleMark's watermark readability after style transfer is not proof of cryptographic owner/content binding. The thesis should define those events and side information explicitly.

For F5, cross-family ranking reversals and an encoder/noise-injection mechanism remain potentially useful only if generalized across published methods or turned into prospectively validated improvement. This is our inference; these four papers do not test that F5 claim.
