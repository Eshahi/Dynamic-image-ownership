## Evidence at the pinned sources

1. A5 currently names the Diffusers-format components of the unaffiliated `stable-diffusion-v1-5/stable-diffusion-v1-5` mirror at revision `451f4fe16113bff5a5d2269ed5ad43b0592e9a14`. Its [pinned card](https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5/blob/451f4fe16113bff5a5d2269ed5ad43b0592e9a14/README.md) explicitly says the mirror is not affiliated with RunwayML and labels CreativeML OpenRAIL-M. The card is a claim by that mirror, not independent custody or a per-component equivalence proof. The server-advertised component hashes are recorded in `environment.md`; no bytes have been checked locally.
2. The [Comfy-Org archive at revision `9cfd069`](https://huggingface.co/Comfy-Org/stable-diffusion-v1-5-archive/blob/9cfd069101959ca3828bf9c04a4419870832b74f/README.md) claims its `v1-5-pruned-emaonly.safetensors` is byte-identical to the retired RunwayML upload. The archive and the A5 mirror advertise the same single-file LFS SHA-256 object ID, `6ce0161689b3853acaa03779ec93eafe75a02f4ced659bee03f50797806fa2fa`. This is useful cross-repository corroboration of **one file**, not first-party attestation, local byte verification, proof about the four Diffusers-format component weights, or a resolution of the applicable terms. The archive's fp16 conversion is a *different artifact* and must not inherit that identity claim.
3. [Diffusers v0.35.1 single-file documentation](https://huggingface.co/docs/diffusers/v0.35.1/en/api/loaders/single_file) lists `StableDiffusionImg2ImgPipeline` as supported, and documents local file, local configuration, and `local_files_only=True` parameters. Its [v0.35.1 layout guide](https://huggingface.co/docs/diffusers/v0.35.1/using-diffusers/other-formats) explains that single-file loading can otherwise infer or fetch configuration from the Hub. This makes the archived single file a plausible way to reduce *weight custody* uncertainty while retaining an existing-image pipeline. It does not establish parity with the multi-folder A5 candidate or compatibility with the thesis's nonstandard inversion/gradient path.
4. The [pinned v0.35.1 loader source](https://github.com/huggingface/diffusers/blob/v0.35.1/src/diffusers/loaders/single_file.py) explicitly treats the safety checker as optional and says it is not loaded from a single file unless separately provided. Therefore a loader success cannot be recorded as a safety-component success. A5's safety path and any associated feature extractor must be separately pinned, hashed, rights-reviewed, loaded locally and tested; do not silently disable them to make the alternate route work.

## Bounded decision

Retain the A5 multi-folder candidate **as an unverified candidate**, not a locked scientific checkpoint. Keep the archived, hash-correlated single-file route as a **contingent fallback** for better weight custody, not an automatic substitution. This avoids silently changing the model-loading route, scheduler/configuration, safety behavior or output numerics. Publisher-owned `CompVis/stable-diffusion-v1-4` is a different model version and is not an equivalence substitute for the specified v1.5 experiment.

Before either route can enter an exact scientific manifest:

- Freeze the precise repository revision and **all** file identities: checkpoint, tokenizer, text encoder, VAE, UNet, scheduler/config, and safety checker/feature extractor. Record license/use restrictions and source attribution. If using the single file, distinguish checkpoint bytes from externally supplied config and safety assets.
- Acquire only after the separate model/dataset-download decision; verify full SHA-256 of local bytes against recorded LFS claims. Do not use floating `main`, implicit downloads, pickle `.ckpt` fallback, or an unlogged conversion.
- For a single-file trial, provide explicit local config, `local_files_only=True`, and explicit safety components; then compare a fixed input/seed/scheduler/precision vector against the chosen multi-folder path, including latent shape, VAE scale, tokenizer output, safety handling and gradients. Record any divergence as a method revision, not as an interchangeable loader.
- If independent source/rights review or numerical equivalence cannot be established, keep A6 and the dependent scientific method gate open. Seek a documented A5 amendment through the existing issue/review path rather than asserting that a mirror is the retired publisher release.

No model or data was downloaded, no Stage-2 package was installed, and no scientific run was started for this decision. The pending Stage-2 software-install question is separate; it does not authorize weights or this alternate loader as the adopted method.
