# Fixed-inventory scientific endpoint arithmetic

Preparation implementation, not an executed confirmatory analysis. `scripts/m1_scientific_analysis.py` consumes the frozen materialized inventory and observations **after the official collector has independently verified their artifacts, scientific core, source lineage and schedule**. It performs no file/model/raw access and cannot certify those upstream checks. Nine CPU tests pass; no held-out observation was inspected.

Each query observation repeats its planned scientific metadata and retains the unchanged detector result in `decision`. Image observations retain `quality_vs_source`. Missing, invalid, altered-identity and malformed detector observations stay in the planned denominator. Extra/duplicate observations are errors. Candidate scores independently reproduce the inclusive4 rule and both flags/state. V5 retains its single-claim profile and own4.982033056390042/8.259326826136963 thresholds, content-match and carrier-presence meanings.

Clean query cells are separate C0-source, matched reconstruction, correct C1 and wrong-owner C1 cells, with one source group per cell. T3 separates every arm, claim, strength and seed; T4 separates patch size, donor arm and claim; T5 separates endpoint direction and arm within the selector's disjoint pairs. A repeated cluster within one binomial cell is rejected, not treated as a new independent sample. Cross-cell and cross-method dependence remains explicit. T5 units require the actual frozen selector output and its complete eligibility ledger; the analyzer does not create qualifying pairs or rescue a shortfall.

Component threshold support is descriptive. Semantic support by itself is not false full attribution, and recipient-own support after T4 is not mislabeled as false donor attribution. Only clean joint cells carry the draft80%/1% numerical flags. Other joint cells retain conservative observed/missing arithmetic without importing those clean targets. Missing positives count as misses; missing negatives count adversely, alongside observed-valid bounds. Exact source-quality inequalities are >35dB, >.9 SSIM and <.1 LPIPS. Human judgments, security and milestone verdicts remain null.

Tests cover opposite adverse missingness directions, descriptor support versus joint attribution, tampered identities/states, repeated-cluster rejection, strict quality boundaries and missing metrics, T4 recipient semantics, descriptive T3 cells, distinct v5 thresholds, and T5 insufficiency. Production collector integration, full scientific run completeness, paired output comparison and source/core artifact audits remain required separately.
