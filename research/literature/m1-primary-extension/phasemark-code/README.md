This repository contains the official PyTorch implementation of the paper:
_**"PhaseMark: A Post-hoc, Optimization-Free Watermarking of AI-Generated Images in the Latent Frequency Domain"**_
([📄 Accepted at ICASSP 2026](https://doi.org/10.1109/ICASSP55912.2026.11463051)).

## 🧭 Overview

<p align="left"><img src="docs/static/images/fig_framework.png" width="900"></p>

PhaseMark is a **post-hoc** watermarking framework that embeds a message directly into the **phase spectrum of a Stable Diffusion VAE latent**. Unlike prior post-hoc latent methods that rely on per-image iterative optimization (ZoDiac: >7 minutes/image) or on DDIM inversion for detection (4+ seconds/image), PhaseMark is a **single-shot transform** — it requires no training, no optimization, and no diffusion model at detection time.

> 🧠 **Built on latent frequency-domain phase**
> - ✅ Post-hoc — works on any already-generated image
> - ✅ Optimization-free, single-shot embedding and detection
> - ✅ Center-aware, Hermitian-symmetric latent Fourier design

### ✨ Key Features

- ⚡ **Optimization-Free & Single-Shot**: Thousands of times faster than optimization-based post-hoc methods — 0.142 s to embed, 0.050 s to detect
- 🛡️ **SOTA Robustness**: 0.999 verification TPR@1%FPR under severe attacks, including VAE and diffusion regeneration
- 🎨 **No Quality Cost**: The quality-centric variant (PCQ) *improves* FID over the VAE baseline (ΔFID-1k = −0.517)
- ⚖️ **Clear Trade-off Control**: Four phase-modulation variants (absolute/relative × hard/soft) let you pick your operating point
- 🔳 **128-bit Payload**: 32 bits per latent channel × 4 channels — enough for identification among 10⁶ users

## 📦 Installation

This project is based on an Anaconda virtual environment. A **CUDA-capable GPU is required** — the scripts raise a `RuntimeError` immediately if no GPU is detected.

```bash
git clone https://github.com/thomas11809/PhaseMark.git
cd PhaseMark
conda create -n phasemark python=3.10 -y
conda activate phasemark
pip install -r requirements.txt
```

## ⚡ Quick Start

We provide `fast_try.py` for **fast watermark embedding and detection** on arbitrary images, without setting up the full evaluation pipeline. It reports per-image **bit accuracy** and **PSNR**.

```bash
# Process every image in a folder (defaults: --method ips --num_embed_ch 4 --axis_offset 1)
python fast_try.py --input_dir /path/to/my_images/

# Process specific files with a different variant
python fast_try.py --images photo1.png photo2.jpg --method sps --num_embed_ch 4

# Embed a custom message
python fast_try.py --input_dir my_images/ --method ips --message "MySecret"
```

Results are written to `fast_try_output/` (watermarked images + the Hermitian-symmetric variant).

Input arguments:
- `--input_dir` / `--images`: Input source — a directory of images, or an explicit list of image paths (mutually exclusive).
- `--method`: Watermarking variant. See [Methods](#-methods) — `apm` | `pcq` | `ips` | `sps`.
- `--num_embed_ch`: Number of latent channels used for embedding (`1`–`4`, 32 bits each).
- `--axis_offset`: Skip the principal frequency axes (`0` = off, `1` = on, default).
- `--message`: Custom payload string. Random bits are used if omitted.
- `--output_dir`: Directory to save output images.
- `--vae_model_id`: HuggingFace repo ID or local path for the VAE.

<details>
<summary>📏 <b>Message length limit</b></summary>

`--message` is encoded as UTF-8 and padded/truncated to `num_embed_ch × 32` bits. The maximum number of **Unicode characters**:

| `--num_embed_ch` | Max message length | Embedded bits |
|---|---|---|
| `1` | 4 characters | 32 bits |
| `2` | 8 characters | 64 bits |
| `3` | 12 characters | 96 bits |
| `4` | 16 characters | 128 bits |

Messages longer than the limit are silently truncated from the right. Multi-byte characters (CJK, emoji) count as one character but consume more than 8 bits each, so they exhaust the bit budget faster than ASCII.

</details>

## 🔍 Methods

<!-- <p align="left"><img src="docs/static/images/fig_methods.png" width="1000"></p> -->

The VAE encoder maps an image to a latent $z_0$. A 2D FFT is applied to its **central crop** $z_{crop}$ (44 × 44 × 4) for spatial robustness, and an $L$-bit message is embedded into $L$ 2 × 2 blocks drawn from **stable mid-band frequencies** (radially bounded by $[10, 18]$), avoiding low-frequency image content and high-frequency noise. **Axis offsets** skip the high-energy principal axes, and **Hermitian symmetry** is enforced so that the inverse FFT yields a real-valued latent. The VAE decoder then reconstructs the watermarked image.

Four phase-modulation strategies are provided, spanning two families:

| CLI flag | Paper name | Family | Modulation | Best for |
|---|---|---|---|---|
| `apm` | **APM** — Absolute Phase Modulation | Absolute | Hard | 🥇 **Robustness** (Vrf. 0.999 / Idf. 0.988) |
| `pcq` | **PCQ** — Phase Constellation Quantization | Absolute | Soft | 🎨 **Image quality** (ΔFID-1k = −0.517) |
| `ips` | **IPS** — Intra-block Phase Synchronization | Relative | Hard | ⚖️ **Balanced** (default) |
| `sps` | **SPS** — Soft Phase Synchronization | Relative | Soft | 🎚️ Tunable via $\gamma$ ($\gamma = 1 \Rightarrow$ IPS) |

**Absolute phase modulation** sets each complex value in a block to a predefined phase, independently of the other elements:

- **APM** *(hard)* — forcibly assigns the phase of every $c \in B_i$ from the message bit $m_i$:

$$\angle c' = (-1)^{1-m_i}\frac{\pi}{2}$$

- **PCQ** *(soft)* — quantizes the original phase to the nearest entry of the constellation set $\mathcal{P}_{m_i}$, minimizing distortion:

$$\angle c' = \arg\min_{p \in \mathcal{P}_{m_i}} |\angle c - p|_{\text{angle}}$$

**Relative phase modulation** encodes the bit in the phase *relationships* inside a block $B_i = \{c_1, c_2, c_3, c_4\}$, where $c_1$ and $c_3$ act as anchors:

- **IPS** *(hard)* — synchronizes $c_2, c_4$ with the anchors while preserving their magnitudes:

$$\angle c_2' \leftarrow \angle c_1 + (1 - m_i)\pi, \qquad \angle c_4' \leftarrow \angle c_3 + (1 - m_i)\pi$$

- **SPS** *(soft)* — linearly interpolates toward the synchronized targets with strength $\gamma$ (we use $\gamma = 0.8$):

$$c_k' = (1 - \gamma)c_k + \gamma \cdot c_{k,\text{tgt}}, \quad k \in \{2, 4\}$$

**Detection** reverses the embedding and reads each bit back from the recovered blocks: APM uses the sign of the summed block phases, PCQ compares the total angular distance to $\mathcal{P}_0$ and $\mathcal{P}_1$, and IPS/SPS use the anchor correlation score $S_i = \cos(\angle c_1 - \angle c_2) + \cos(\angle c_3 - \angle c_4)$. A watermark is declared when the bit accuracy exceeds a threshold $\tau$ calibrated for a 1% FPR (with a Bonferroni correction for identification among $N = 10^6$ users).

Applying the axis offset improves image quality (higher PSNR, lower LPIPS) at the cost of a minor drop in detection performance, so it is enabled in all final models.

## 🧪 Evaluation

### 🗂️ Datasets
---
We evaluate on 1,000 images of 512 × 512 resolution per dataset, generated with Stable Diffusion v2-1-base (CFG = 7.5, 50 DDIM steps) from the following prompt sets:

- `coco`: MS-COCO-2017 captions
- `Gustavo`: [SD-Prompts](https://huggingface.co/datasets/Gustavosta/Stable-Diffusion-Prompts)
- `DB1k`: [DiffusionDB](https://huggingface.co/datasets/poloclub/diffusiondb)

`--dataset_id` accepts `coco` | `Gustavo` | `DB1k` and determines the output sub-directory naming.

### 📁 Data Preparation
---
**Input images.** Pass the directory that *directly* contains your images via `--input_dir`. Files **must be named as integer indices** (`0.png`, `1.png`, …, `N-1.png`), 512 × 512 RGB PNG. Use `--num_images N` to limit how many are processed.

```
my_images/
├── 0.png
├── 1.png
└── ...
```

**FID reference set** (required only for `measure_fid1000.py`). Download [COCO val2017](https://cocodataset.org/#download) and build the 1,000-image reference subset:

```bash
python make_subset1000-coco-gt.py --source_dir /path/to/coco/val2017

# To reproduce the exact subset used in the paper, follow a COCO-style metadata file:
python make_subset1000-coco-gt.py \
    --source_dir /path/to/fid_outputs/coco/ground_truth \
    --meta_json  /path/to/fid_outputs/coco/meta_data.json
```

This populates `coco-ground_truth-subset1000/`, which `measure_fid1000.py` reads by default (override with `--gt_dir`).

### 🚀 Usage
---
To run the entire pipeline **from scratch**, use the following commands in sequence. The `--output_dir` you choose is reused across every step.

```bash
# 1. Embed watermarks and save the watermarked images
python main.py --mode generate --dataset_id coco --method ips --num_embed_ch 4 \
    --input_dir /path/to/images/ --num_images 1000 --output_dir output-ips

# 2. Apply signal-processing and cropping attacks
python main.py --mode attack --dataset_id coco --method ips --num_embed_ch 4 \
    --output_dir output-ips

# 3. Run the diffusion-based regeneration attack (GPU-intensive)
python main.py --mode diff_attack --dataset_id coco --method ips --num_embed_ch 4 \
    --output_dir output-ips

# 4. Detect the watermark across every attacked variant
python main.py --mode detect --dataset_id coco --method ips --num_embed_ch 4 \
    --output_dir output-ips

# 5. Print the performance table and export it to Excel
python main.py --mode show_results --dataset_id coco --method ips --num_embed_ch 4 \
    --output_dir output-ips
```

This example uses `ips`; swap `--method` for `apm`, `pcq`, or `sps` to reproduce the other variants. Output folders inside `--output_dir` are named `{N}ch-{bits}bit-offset{axis_offset}` (e.g. `4ch-32bit-offset1`).

> 💡 The Stable Diffusion pipeline used by `diff_attack` is loaded **lazily**, so the other modes are unaffected by that large model. It defaults to `sd2-community/stable-diffusion-2-1`; pass `--diff_attack_model_id Manojb/stable-diffusion-2-1-base` to use the lighter base model instead.

#### 🎯 Attacks
The `attack` and `diff_attack` modes cover the nine perturbations evaluated in the paper:

| Category | Attacks |
|---|---|
| Signal processing | Contrast (0.5), JPEG (Q = 25), Gaussian blur (r = 5), BM3D (σ = 0.1) |
| Regeneration | VAE-B, VAE-C (quality level 3), Diffusion (60 steps) |
| Cropping | Center crop (C.C.), random crop (R.C.) — 0.5 / 0.7 scale |

#### 📐 Measurement Scripts

```bash
# VAE reconstruction quality (PSNR / SSIM / LPIPS, without watermark)
python measure_reconstruction.py --mode measure_recon --dataset_id coco --method ips \
    --input_dir /path/to/images/ --output_dir output-ips

# Embedding / detection latency
python measure_performance.py --mode measure_perf --dataset_id coco --method ips \
    --num_embed_ch 4 --input_dir /path/to/images/ --output_dir output-ips

# FID between the watermarked images and the COCO reference set
python measure_fid1000.py --dataset_id coco --method ips --num_embed_ch 4 \
    --output_dir output-ips   # --gt_dir defaults to coco-ground_truth-subset1000/
```
