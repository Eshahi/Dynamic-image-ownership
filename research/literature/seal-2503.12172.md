# SEAL — Semantic Aware Image Watermarking (arXiv 2503.12172, v4 2026-05-18)

- URL: https://arxiv.org/abs/2503.12172
- Access: abstract + B1 targeted inspection Section 3.2 / Algs 1-3 (prior).

## Claim
Binding watermark to semantics via LSH enables distortion-free detection without key dictionary and improves forgery robustness.

## Mechanism
Generation-time (initial noise). Semantic embedding conditions key via SimHash/LSH. Detection inverts diffusion, checks noise agreement conditioned on semantics. Secret salt.

## Threat model
Attacks: (i) noise extraction + reprompt, (ii) object insertion while preserving watermark. Not T3 regeneration of existing photos.

## Limits
Not post-hoc; requires diffusion inversion.

## Relevance to F5
Closest semantic-binding precedent. F5 remaining failures are binding (0 carrier failures at .2/.4). Supports soft binding / multi-view stabilization.
