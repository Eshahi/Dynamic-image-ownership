# Redesign brief: watermark that survives diffusion regeneration

Self-contained: paste it as the first message of a fresh chat with any model. Written 2026-10-02.

## Goal

Master's thesis "Dynamic Image Ownership With Robust Neural Watermarking". Design an embedding and extraction method that keeps an owner's mark through diffusion-model regeneration, and still resolves copy-paste forgery and semantic collisions. The proposal's own method (below) is the target; additions are allowed, contradictions are not.

## Proposal method (fixed)

1. Dual-key signature. A CLIP embedding E and a DCT-based perceptual hash H of the image, plus the OwnerID, give a semantic key Ks = hash(E, owner) and an instance key Ki = hash(E, H, owner).
2. Latent embedding. The watermark is injected as part of the initial Gaussian noise of a diffusion model, so it is intrinsic to the generated structure and should survive regeneration.
3. Lightweight extraction, with no heavy decoder and no diffusion inversion. Re-derive candidate keys from the suspect image, take 8x8 block DCT, correlate mid-band coefficients with the pattern expected from the keys. Decisions: authentic (both keys found), regenerated (only Ks found), copy-paste forgery (a mark is present but does not match the current image's semantics).

## Current state (what exists)

Image-domain codec `revised_watermark_v4.py` (revision 2): sign-projection codes for both keys, improved spread spectrum on disjoint 8x8 DCT coefficient sets, 42 dB PSNR budget, correlation detector with a Hoeffding threshold, codes also stored as helper data so transplants are flagged `content_mismatch`. Stdlib Python, CPU, 512x512 RGB.

## Measured on 12 COCO images (exploratory, single run, run id c4-v4r2-three-threat-dev-001)

- Clean: 12/12 detected (both keys), PSNR about 42 dB, no false detections on 48 unmarked and 36 wrong-owner checks.
- Regeneration (SD 1.5 img2img, DDIM 20 steps, strengths .05/.1/.2/.4, 3 seeds, plus a deterministic VAE encode/decode round trip with no diffusion): **mark lost at every dose, including the VAE round trip alone**. Detector scores of marked images fall to the level of unmarked controls (about 1 against a threshold of 5.6) while CLIP similarity to the source stays 0.97 to 0.90. So the loss is not "attenuated", it is gone.
- Copy-paste (the donor's mark transplanted onto another image by copying its 640 public carrier projections): the mark was delivered into all 20 recipients and all 20 were correctly rejected as content mismatch. Patch and band copies gave no admissible outputs.
- Semantic collision: only 3 of 7 same-semantic pairs had near semantic codes; inconclusive.
