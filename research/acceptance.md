# A4 preregistered acceptance contract (design draft)

Status 2026-09-23: **prospective documentary design**, not a frozen executable protocol, observed result, institutional target, or compute authorization. Issue #5. Authority: the 42 unchanged rows in `claims.csv`, `research-contract.md`, `scope-guard.md`, A3 interfaces/threat model, and the untested A5 method candidate. Changes after seeing held-out outcomes are exploratory and must not overwrite this record. `sample-size.md` and `stop-rules.md` are part of this contract.

## Study primary outcome and decision

The one study-primary endpoint is the fraction of independent held-out source images whose **encoded, re-decoded, untouched marked output** returns `both_match` for its enrolled public OwnerID at one validation-frozen `(tau_s,tau_i)` and method configuration. The analysis unit is a source image/content group, not a seed, candidate key, transformed image, DCT block, or owner trial. Every enrolled image attempted contributes to the denominator; invalid source/embedding/detector failures are counted separately and count as failure for end-to-end coverage. Report intention-to-process and valid-output conditional rates, with the former primary.

The complementary false-match endpoints are `both_match` on C0 unmarked source, C0 matched unmarked reconstruction, and C2 wrong-owner marked output, each separately by domain. A single tested wrong owner (`K=1`) is the primary candidate-set profile; its OwnerID is selected deterministically from a predeclared disjoint identity roster before scores are seen. Report the roster, exact selection algorithm, and any-of-K sensitivity separately if K>1 is later preregistered. Do not generalize K=1 FPR to many-owner search or authenticated/legal ownership. C0 and C2 share parent images with C1, so cross-condition comparisons are paired; the distinct source images/content groups are the independent units for within-condition binomial intervals.

For the primary controlled study, the public synthetic roster is exactly `thesis:owner:00` through `thesis:owner:15`, with two decimal digits and no real person's identity. Let `source_uid` be the globally unique, nonempty NFC UTF-8 source identifier frozen in B3/B4 before image outcomes are inspected; reject missing/duplicate IDs or a UTF-8 byte length exceeding `2^32−1` rather than inventing replacements. Define `D(tag,u)=SHA256(ASCII(tag) || 0x00 || uint32be(len(u)) || u)`, with `u` the exact UTF-8 bytes. The enrolled owner index is the unsigned big-endian integer in the first eight bytes of `D("a4-owner-v1",u)` modulo 16; C2 tests exactly the next roster index modulo 16. The one primary embedding seed is the unsigned big-endian integer in the first eight bytes of `D("a4-seed-v1",u)`, including zero if produced. This seed is public deterministic scheduling, **not** a secret; it is distinct from A5's global semantic-projection seed and is combined with the source-byte hash by A5's base-noise rule. The per-source resolved method configuration's `embedding.noise_seed` and `embed_existing(..., seed)` argument must both equal this exact uint64; record the resolved config and a fixed-width 16-digit lowercase hex seed receipt. The method schema currently represents `noise_seed` as a JSON integer, so its parsing and any transport must preserve the full uint64 exactly: ordinary IEEE-754 JavaScript number conversion is not sufficient, as the example exceeds `2^53−1`. No best-of-seed retry is allowed for the primary endpoint. Illustrative parity vector only, not a selected data ID: `source_uid="coco:000000000001"` gives enrolled index 9, wrong-owner index 10 and seed `4369173439443558334` (`0x3ca26c18241adfbe`). Actual source IDs, group membership and eligibility still require B3/B4 freeze; a later ID-format change must be versioned before any validation/test scoring. Multi-owner `K>1` and multi-seed sensitivity profiles remain separate `BLOCKED_PROTOCOL`, not an implicit extension of this K=1 primary rule.

**Draft technical operating objective, not proposal/university requirement:** target test FPR ≤1% in *each* C0/C2 negative stratum and domain, assessed by a one-sided 95% exact binomial upper bound with a threshold fixed on disjoint validation data. This stringent value is chosen because 300 independent negatives with zero matches can resolve ~1%; it is a design choice to be reviewed/frozen before any test. If validation has no pair satisfying the negative-cell constraint, record failure rather than loosening the target after inspection. If an eligible pair has poor or even zero positive detection, still freeze the stated tie-break winner and evaluate the primary TPR objective; no subjective "usefulness" veto or post-hoc threshold search is allowed. The primary positive objective is a draft **TPR ≥80%**; declare it met only if its one-sided 95% exact lower bound is ≥0.80 in each source domain and all negative upper bounds meet 1%. This 80% floor is a provisional practical requirement (up to one missed valid mark in five), not a proposal-stated threshold or evidence of adequacy for real rights enforcement. Report point rates and two-sided 95% Wilson intervals even when the joint objective fails. The joint **all-cells** objective uses an intersection-union test: only if every per-cell one-sided level-0.05 component passes is the conjunction accepted at level 0.05; individual cell intervals are not thereby simultaneous 95% intervals. This is conditional on independent source groups within each cell, frozen thresholds, and fixed analysis/failure rules.

On validation only, select a **single common** threshold pair from the prespecified grid `G={(j−50)/50 : j=0,...,100}` for each component (`101×101=10,201` pairs, both endpoints included). The mathematical score comparison is strictly `score > threshold`, including at exact ties; implement the grid from integer indices rather than accumulated floating-point increments. Among pairs satisfying empirical C0-source, C0-reconstruction, and C2 FPR ≤1% *in each domain*, maximize macro-average C1 TPR across the three domains, then choose the pair with larger `tau_s`, then larger `tau_i`. Compare eligibility with integer counts (`100×false_matches ≤ planned_cell_N`), not rounded percentages. Every predeclared eligible validation source remains in its cell denominator: an invalid/absent C1 result counts as a miss, and an invalid/absent negative-condition result counts as a false match **for threshold eligibility**. Also report the observed-valid negative rate separately. This conservative missingness convention prevents a failing route from appearing to have low FPR; it is not a claim that a missing detector actually matched. The grid, synthetic-owner/seed schedule and failure rule are now **frozen documentary choices before validation scoring**; actual dataset IDs, group eligibility and implementation parity remain `BLOCKED_DATA/PROTOCOL`. Empirical validation FPR is a calibration constraint, not an unbiased confidence bound, because thresholds are selected on those same data. Never use held-out test values to choose thresholds, embedding parameters, attack severity, owner roster, or a preferred seed. If no pair qualifies, the frozen method has no admissible operating point and the outcome is negative/inconclusive as appropriate; do not report an oracle test-optimized threshold as primary.

`scripts/a4_protocol_reference.py` and its synthetic unit tests encode this owner/seed and calibration rule on **precomputed scores only**. The same reference evaluates one-sided 95% exact binomial bounds from adverse-coded test counts and the 12-cell joint objective; it never infers independence or eligibility from counts. Passing these tests checks arithmetic and tie/failure semantics, not split isolation, source eligibility, A5 detector parity, observed performance or authority to run an experiment. The eventual runner must verify exact resolved-config/seed equality and compare its calibration and bound outputs against these reference outputs before test unlock.

All scores retain continuous ROC/AUC analysis; `both_match` requires a common semantic candidate as A5 specifies. For a valid detector output, define the **joint continuous margin** `M(J,o)=max_q min(S_s(q)-tau_s, max_h S_i(q,h)-tau_i)` over A5's common-q candidate set, considering only finite, non-`zero_variance` component candidates that are eligible to match under A5. For each q, the maximum over h uses only eligible instance candidates; q itself is eligible iff its semantic component and at least one instance candidate are eligible. If every q is ineligible, assign the finite ranking sentinel `M=-3` (below the possible eligible margin range `[-2,2]`), record `all_candidates_vetoed`, and treat it as a nonmatch; the sentinel must not be mistaken for a measured cosine score. At the frozen zero cutoff, `M>0` is exactly `both_match`; vary only the scalar cutoff on held-out scores to construct descriptive ROC/AUC, without refitting either component threshold. Report semantic and instance component ROC/AUC separately and state the positive/negative class construction for each family. ROC/AUC is **valid-output conditional**: invalid outputs have no M and stay in the failure/coverage inventory, not silently dropped or assigned a favorable score. A source-key oracle, enrollment-reference detector, or altered presence witness is a diagnostic/comparator, never substituted for the blind core detector. `semantic_only` is a component observation, not a regeneration/copy-paste diagnosis. Public OwnerID does not authenticate enrollment. The latent-to-DCT bridge must show C1 score separation from **both** matched C0 and wrong-owner C2 on decoded outputs under the same model path; source-template continuous optimization scores alone do not satisfy this endpoint. A failed bridge is a valid negative scientific result, not permission to relabel an image-domain baseline as the proposed method.

## Prospective image-quality measurement profile

This is a **measurement choice before data**, not a report that the proposal's PSNR >35 dB, SSIM >0.9 or LPIPS <0.1 targets have been achieved. For each eligible source, compare canonical oriented/color-converted RGB8 source pixels `I` with the **decoded saved PNG** `Iw` on the original H×W grid. Report the same three metrics separately for matched unmarked reconstruction `Iref` when available; do not subtract its reconstruction loss from the primary `I`–`Iw` quality result. Use no resizing, crop, registration, masking, channel substitution or per-image exposure correction to improve a score. A shape mismatch, failed source conversion, missing output or nonfinite pixel is an invalid quality observation with a reason in the source-level failure inventory, not a zero-distortion result. The A5 canonical RGB8 sRGB decode/encode policy applies to all three images. These choices are consistent with the same-shape requirements of the [scikit-image 0.26.0 PSNR/SSIM API](https://scikit-image.org/docs/0.26.x/api/skimage.metrics.html) and the [official LPIPS input contract](https://github.com/richzhang/PerceptualSimilarity/tree/082bb24f84c091ea94de2867d34c4544f68e0963).

| Metric | Proposed exact call on the canonical aligned pair | Output rule |
| --- | --- | --- |
| PSNR | `skimage.metrics.peak_signal_noise_ratio(I, Iw, data_range=1.0)` after RGB8/255 conversion to an H×W×3 floating array | One value in dB per source. Identical pixels give +infinity: store an explicit `identical_pixels` flag and a null JSON numeric value, not nonstandard JSON `Infinity`; count it as strictly above 35 dB. Other nonfinite results are invalid. |
| SSIM | `skimage.metrics.structural_similarity(I, Iw, data_range=1.0, channel_axis=-1, gaussian_weights=True, sigma=1.5, use_sample_covariance=False, K1=0.01, K2=0.03)` on the same H×W×3 floating arrays | One RGB-channel-averaged value per source; reject nonfinite output. Explicit range and Gaussian/covariance settings follow the [upstream Wang-style recipe](https://scikit-image.org/docs/0.26.x/api/skimage.metrics.html#skimage.metrics.structural_similarity), avoiding the documented float-range ambiguity. |
| LPIPS | Pinned [upstream code commit `082bb24f84c091ea94de2867d34c4544f68e0963`](https://github.com/richzhang/PerceptualSimilarity/blob/082bb24f84c091ea94de2867d34c4544f68e0963/lpips/lpips.py): learned `alex` trunk, version `0.1`, spatial=False, evaluation mode; convert the same RGB8/255 pair to `[1,3,H,W]` float32 tensors, map to `[-1,1]`, call with `normalize=False` under no-grad, and retain the scalar | One distance per source; reject nonfinite output. The upstream code uses both its small `v0.1/alex.pth` linear-layer file and a TorchVision-pretrained AlexNet trunk; a package name or the 6,009-byte GitHub weight blob alone does **not** identify all model weights. Do not allow implicit network download during evaluation. |

The per-image target indicators use the proposal's **strict** inequalities (`>35`, `>0.9`, `<0.1`); equality does not pass. For each domain and each comparison pair, report attempted/valid/missing counts, median, quartiles, range, target-pass count over the full eligible-source denominator and valid-output-conditional pass count. An unavailable metric is an adverse failure for the full-denominator descriptive pass fraction, but is not silently assigned an artificial PSNR/SSIM/LPIPS value. A5 permits images as small as 32×32, whereas the candidate TorchVision [AlexNet weight profile specifies minimum 63×63](https://docs.pytorch.org/vision/master/models/generated/torchvision.models.alexnet.html) and its pinned [feature stack includes three downsampling pools](https://github.com/pytorch/vision/blob/v0.27.1/torchvision/models/alexnet.py). Therefore a source under 63 pixels on either axis is `lpips_unsupported_resolution` for this candidate, not an invitation to silently upscale; inventory it and assess actual dataset eligibility before freeze. No study-level quality success fraction or noninferiority margin is invented from the proposal; those claims remain descriptive or `BLOCKED_PROTOCOL` until a justified rule is frozen before held-out access. Threshold calibration does not use the quality values of locked test images. The exact scikit-image package build, LPIPS code installation, both LPIPS weight SHA-256 receipts, Torch/TorchVision versions, CPU/GPU numerical parity and native-resolution memory behavior remain A6/runtime checks. The pinned upstream [LPIPS license](https://github.com/richzhang/PerceptualSimilarity/blob/082bb24f84c091ea94de2867d34c4544f68e0963/LICENSE) was inspected for code redistribution terms; it does not by itself establish the TorchVision checkpoint's acquisition terms. No model bytes or scientific images were downloaded or evaluated for this design entry.

## T1 fixed-transform secondary profile (design before data)

T1 tests four **single**, nonadaptive transformations of the saved canonical RGB8 `Iw` image, each independently starting from untouched `Iw`; there are no chains, best-of-attempts, or detector queries during construction (`Q=0`). The families are motivated by published watermark robustness evaluations such as [Gaussian Shading (CVPR 2024)](https://openaccess.thecvf.com/content/CVPR2024/papers/Yang_Gaussian_Shading_Provable_Performance-Lossless_Image_Watermarking_for_Diffusion_Models_CVPR_2024_paper.pdf); the **numbers below are this study's prospective choices**, not claimed to be that paper's settings or proof that the outputs are benign. T2 removal, T3 regeneration, T4 transfer, T5 collision and T6 public re-embedding still require separate protocols. No T1 outcome is part of the 12-cell primary clean-image objective.

| T1 family | One fixed operation per selected image | Required implementation receipt |
| --- | --- | --- |
| JPEG | Encode RGB8 once at quality `75`, chroma subsampling `0` (4:4:4), `progressive=False`, `optimize=False`; decode once to RGB8 at the original H×W. | Pin Pillow and JPEG library/build, encoder options, JPEG-byte and decoded-PNG hashes. [Pillow's JPEG option contract](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html) distinguishes quality, subsampling, progressive and optimize. |
| Resize | Set `W'=max(1,floor(0.75W+0.5))`, analogously `H'`; resize RGB8 to W'×H' and back to W×H with `PIL.Image.Resampling.BICUBIC` both times. | Pin Pillow build and retain intermediate size and output hash; do not silently use a default filter or `reducing_gap`. |
| Center crop/restore | Set `W'=max(1,floor(0.90W+0.5))`, analogously `H'`; crop `[floor((W-W')/2), floor((H-H')/2), +W', +H']`, then bicubic-resize to original W×H. | Record crop box, Pillow build and output hash. This retains about 81% of image area, not 90% area. |
| Additive noise | In sRGB unit-range channel order, add independent zero-mean unit-normal variates scaled by `0.01`, clip to `[0,1]`, multiply by 255 and round to nearest integer, ties to even. Generate the normals using A5's declared uint64/Box–Muller mapping from a SHAKE256 stream keyed by `ASCII("a4-t1-noise-v1") || 0x00 || uint64be(a4_seed) || uint32be(len(source_uid_utf8)) || source_uid_utf8`; consume in row-major RGB order. | Pin the numeric implementation, produce known-answer pixel vectors, record seed and output hash. No stochastic retries. |

The fixed T1 evaluation cohort is **300 independent locked-test source groups per domain** (900 total). Choose each group's representative as its lexicographically smallest source UID byte string, then select groups before scoring by ascending `SHA256(ASCII("a4-t1-cohort-v1") || 0x00 || uint32be(len(source_uid_utf8)) || source_uid_utf8)` of that representative, using ascending representative UID bytes for a digest tie. Select from eligible locked-test groups *after* the B3/B4 identity and grouping freeze; no replacement is chosen after attack or detector outcomes. If fewer than 300 eligible groups exist in a domain, report the shortfall rather than filling from validation or another domain. This is a **secondary descriptive cohort**, not extra independent N for the primary clean-image test. The four-family minimum is 3,600 marked-image transform outputs and 3,600 correct-owner detector calls; C2 wrong-owner scoring reuses each attacked image, so at least 7,200 detector calls, before unmarked controls or failures. Benchmark per-image wall time and storage on development IDs before a bounded execution manifest; these counts are not approval to run it.

`scripts/a4_protocol_reference.py:select_t1_cohort` is a standard-library reference for this ranking and explicit per-domain shortfall on **caller-supplied** group records. Its synthetic tests cover byte-order representative selection, input-order invariance, the fixed digest vector and duplicate/noncanonical rejection. It does not establish that those records are licensed, eligible, independent or in locked test; a later B3/B4 manifest validator and independent protocol review must establish those facts before use.

The same file's scalar `t1_noise_rgb8` reference checks the predeclared SHAKE256/Box–Muller/noise/rounding semantics on supplied canonical RGB8 bytes. A synthetic 2×1 known-answer vector with `source_uid="coco:000000000001"` and pixels `(0,128,255,64,128,192)` produces `(2,124,255,64,126,190)`; no scientific image or model was used. This Python reference does not pin a production image decoder, prove bit parity in an optimized backend, or override the resource and compute gates.

Evaluate C1 correct owner and C2 wrong owner on the *same* attacked output under the already-frozen clean validation threshold; compare to the untouched C1/C2 result for that source. Transform matched C0-source controls by the same operation and report their false matches separately; do not claim an attacked C0-reconstruction result unless it is actually produced. Report all attempted, valid, invalid and missing outputs by domain/family, with descriptive source-group Wilson intervals on correct-owner survival and wrong-owner/source false matches. Report attack PSNR/SSIM/LPIPS against `Iw`, and end-to-end quality against `I`, with the same alignment/color/metric rules above; these are distortion descriptors, **not** a retrospective admissibility filter. Invalid transforms or detector scores stay in the intention-to-process count as failures of positive survival and adverse/unresolved negative outcomes, with valid-only rates in parallel. Neither a high survival rate nor a low-distortion label may be generalized to stronger severities, adaptive attacks, all JPEG encoders or cropping without restoration. Before any T1 execution, verify implementation parity on synthetic/development images, exact dataset IDs, pinned metric/runtime builds and the authorized resource manifest; otherwise this profile remains documentary.

For all empirical rows, report domain-stratified numerator/denominator, uncertainty and failures; `I`, `Iw`, `Iref`, C0–C6 and T0–T9 have the meanings in A3/A5. A listed direction is a hypothesis, never an achieved result.

## Inference, families and exclusions

Primary joint intersection-union rule is evaluated once on locked test at the frozen profile, with 12 components: three domain C1 TPR floors and three domains × three negative strata FPR ceilings. Because the joint null is the union of component failures, requiring **all** level-0.05 component tests to pass controls the false joint-success declaration at 0.05; it does not license a separate success claim for each cell or each RQ at that overall level. This rule must be independently reviewed and frozen before test unlock. The four RQ families above and EXP-QUALITY/ROBUST/DOMAINS are secondary; report all endpoints, confidence intervals, denominators and deviations even if the primary fails. Metric-specific superiority/noninferiority margins and secondary-family multiplicity cannot be finalized until B2 comparators, attack profile and expected paired disagreement are fixed; these are **BLOCKED_PROTOCOL for confirmatory secondary claims**, not grounds to run post hoc significance tests. Secondary p-values, if later used, need a precommitted family and correction; otherwise label exploratory. A nonsignificant difference never proves equivalence or noninferiority. For a noninferiority claim, require an independently justified positive loss margin `delta`, and show the appropriate paired confidence bound lies within `delta` on a locked test; no such margin is yet approved. Statistical interval formulas are cross-checked against [NIST's binomial interval guide](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/propconf.htm); the joint conjunction principle follows the [published intersection-union test account](https://pmc.ncbi.nlm.nih.gov/articles/PMC2752611/).

Invalid inputs, missing files, incompatible RGB/profile/resolution, failed gradients, absent baselines, nonfinite scores and timeouts remain in the inventory and intention-to-process denominator. Do not delete a difficult domain, failed seed or negative outcome. On locked test, apply the same conservative missingness rule to each negative FPR upper-bound calculation and report valid-only FPR in parallel; any cell with fewer than 299 independent planned/observed negative groups or compromised grouping is marked insufficient to resolve the 1% target, irrespective of an apparently favorable point estimate. Quality endpoints retain the proposal's **per-image** PSNR >35 dB, SSIM >0.9 and LPIPS <0.1 targets. Report each metric's full valid-output distribution and the intention-to-process fraction meeting all three simultaneously; a failed/invalid image fails that conjunction. No numerical **study-level** pass fraction is inferred from the proposal, so these summaries cannot justify a blanket statement that the study or every domain met its quality targets. Metric implementations, alignment and a revised study-level criterion remain `BLOCKED_PROTOCOL` if such a confirmatory claim is desired. Technical conformance (determinism, finite outputs, correct shapes, explicit C0/C1/C2 controls, source/owner separation and no train/validation/test leakage) is prerequisite to scientific evaluation, not a performance result. A full scientific run still requires exact data/model/code hashes, environment, seeds, manifest, cost/time ceiling and user compute authorization.
