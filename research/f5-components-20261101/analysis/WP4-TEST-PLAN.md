DERIVED: Each existing tier runs a recomputed and decoded test, each at nominal alpha=1e-6; their OR has a union upper bound 2alpha per tier and 4alpha over both tiers. O itself uses only three routes: decoded semantic plus decoded/recomputed instance, so its conditional union bound is 3alpha. A stricter fixed-record endpoint O_U allocates alpha/4 to each included route; its bound is <=.75alpha (one share unused) under the same random-sign, conditional-null assumptions as the base statistic. Content filtering cannot enlarge that rejection event. Decoded multiplicity is 2^32 and recomputed multiplicity 1 per tier only if the selected instance q is independent of instance-pattern randomness under that null. Also report the conservative enumeration over all 2^32 possible q values (2^64 decoded and 2^32 recomputed instance patterns), which avoids relying on q-selection independence. Neither calculation is a guarantee against an adaptive attacker with the fixed public key.

## T2: Exact constrained decoding

DERIVED: For each of the 32 independent segments, compute scores s_j(0),s_j(1) against the saved image projections. Starting from the suspect's saved recomputed semantic code q, form flip gains g_j=s_j(1-q_j)-s_j(q_j). The exact maximum over Hamming distance <=r is the base score plus the largest up to r positive gains, divided by the common projection norm. This is exact because segments are disjoint and the constraint counts flips. Tie handling retains q, then increasing segment index. Compare against recomputed-only and the two-candidate lower bound (recomputed or unconstrained optimum if inside ball). Assert lower<=exact<=unconstrained and validate on exhaustive small synthetic segment cases.

JUDGMENT: r=3 is the prespecified primary radius, motivated by the prior Gate-1 question, with r=0,1,2,4,6 descriptive sensitivity only. A single-radius test uses sum_{j=0}^r choose(32,j) patterns in its nominal bound at alpha=1e-6. No report-half selection among radii. Calling an OR across radii would require an additional allocation. Use saved suspect q from the journal to avoid an unnecessary CLIP recomputation; this is explicit saved development side information, and production would still need its own CLIP pass. Compare current C/J, old lower bound and exact-ball acceptance separately; ball acceptance is not decoded semantic identity.

JUDGMENT: Start with v5 pixel projections, then pinned SD1.5 VAE in CPU inference mode only for F5. Use the same saved marked, C0 and wrong-owner images/cells and profile. Audit available development T4/T5 images by explicit manifests; do not search or open held-out image pools. Measure reader runtime in bounded batches before increasing batch size. Changes to CPU floating-point arithmetic may differ from saved GPU scores; report discrepancy and do not substitute recomputed scores into frozen C/J.

JUDGMENT kill rule: reject exact-ball decoding as a recovery lead if r3 has no extra EVALUATE acceptances beyond the two-candidate bound, or any new EVALUATE negative event. If score replication fails beyond absolute 1e-3 for v5 or 0.05 for CPU F5, label the affected comparison numerically unvalidated and diagnose before interpreting gains. A gain without existing T4/T5 pixel panels remains UNSAFE/UNKNOWN and requires queued T4/T5 testing. Synthetic exactness failure is an implementation blocker, not a scientific negative.

## T4: Final-margin shortfall versus later survival

JUDGMENT: Link each saved final clean margin median/minimum/negative-chip count and clean quality to that source's later robust-tier decoded scores, found/read flags and C/J, separately by cell. No optimizer runs. Primary predictor is clean median margin; primary outcome is the average robust decoded score across available foreign native cells SDXL .1/.2/.4 and K3 .2. JUDGMENT: Freeze the predictor cut at the DESIGN-half median. On EVALUATE report Spearman midrank correlation and high-minus-low group means and success rates; no p-value or causal claim. Negative-chip count and PSNR are diagnostic covariates, not post-hoc replacements for a failed primary predictor.

JUDGMENT kill rule: reject the simple predictive-shortfall account if EVALUATE Spearman rho is <0.30 or the high-margin group's mean foreign decoded score is not greater. ### T0: Semantic/code bottleneck diagnostic

JUDGMENT: On the same complete journals and fixed halves, compare source q, recomputed suspect q and unconstrained decoded q. Report semantic drift and decoded transport errors separately; retain no-read and missing calls. A binding-only oracle changes only decisions on already-read words. Kill a claim that a binding-only change is the primary foreign-native repair if its EVALUATE source-cell headroom is less than 10% of the total frozen-C loss in those cells. This is a ranking rule, not a claim that all descriptor replacements have that ceiling. Do not fit a new descriptor or threshold.

DERIVED: Inspect the public profile's two ten-chip options per semantic segment for the two existing owner IDs. ## TQ: Final residual concentration (prospective addition)

JUDGMENT: This rule is written before this diagnostic is executed. Use only the already fixed first-eight Stage-2 sources, clean C0 and F5/v5 marks, with the same four/four split. Partition each original RGB8 image into nonoverlapping32x32 patches. Rank patches by mean absolute horizontal/vertical luma difference on C0 only; bottom and top quartiles are the fixed flat/textured masks. Measure RGB residual RMS globally, by patch and within those masks, plus maximum absolute residual. No LPIPS/SSIM or human verdict is inferred from these numbers.

JUDGMENT kill rule: reject the claim that local concentration is demonstrated as a reason to prioritize a new cap if neither EVALUATE median max-patch/global RMS exceeds2 nor EVALUATE median flat/textured RMS exceeds1.5. Passing this screen only establishes nonuniform cost; it does not prove a visible flaw or that a cap improves T3. A cap's equal-quality T3/T4/T5 test needs new writing and remains queued. No patch selected using residual outcomes and no threshold tuned on EVALUATE.
