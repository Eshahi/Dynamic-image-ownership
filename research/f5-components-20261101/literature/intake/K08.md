## C. Proposed literature synthesis for K08

JUDGMENT — PROPOSED: The component should remain “second carrier, instance code and write order.” Literature supports separating three questions: whether any carrier survives, whether its payload decodes, and whether that payload remains bound to the suspect content. Improving the first does not establish the third. The strongest simpler comparison is the already-saved robust-only reader outcome versus second-only and either-carrier outcomes at a matched false-positive budget; this is not a robust-only writer experiment and cannot identify writing interference causally.

SOURCE: Gate-1/WP1 development observations in components/K08-fragile-tier.md show second-carrier retention where the robust tier fails, with different 512/1024 processing paths. These observations motivate diversity and scale hypotheses, not intrinsic fragility or a literature-established explanation. Frozen C remains distinct from exploratory composite endpoints. No held-out number is used for tuning.

JUDGMENT — PROPOSED: New since 2024 are better separated objectives, explicit order/interference comparisons, joint latent marking and score-level carrier fusion. None of these reviewed results solves F5's joint requirement: foreign-autoencoder regeneration survival, strict individual-image quality, and safe T4/T5 binding when semantic evidence is absent. The journal local-tamper results should constrain architectural claims, not be promoted to regeneration evidence.

DERIVED: For carrier acceptance events A and B, P(A union B) <= P(A)+P(B) without independence. Thus independently valid per-arm budgets alpha/2 are sufficient for union control at alpha; two arms each calibrated at alpha generally are not. A learned fusion score needs its own held-out calibration distribution. Owner/code searches and any threshold selection consume additional error budget. Correlated carriers do not justify multiplying marginal false-positive rates.

DERIVED: A 32-bit instance code does not itself imply a 2^-32 false-match probability when its bits or candidate images are dependent. Recovering the code demonstrates transmission; matching a recomputed code is a separate, distribution-dependent content check. A public reproducible payload is not a signature or proof of an owner's exclusive embedding capability. No reviewed paper changes that logical distinction.

JUDGMENT — PROPOSED: Preserve the current writer while investigating saved-output complementarity and resolution strata under the root protocol. Separate second-carrier presence, instance-code agreement and robust semantic acceptance, including wrong-owner/unmarked calls. If later authorized, an independently varied write order requires newly generated marked images and belongs in the server queue. It is not testable by relabeling the existing outputs.

JUDGMENT — PROPOSED: Scale is an unresolved confound: carrier coefficients operate in image/block coordinates, while regeneration and resizing can change their effective physical scale. No reviewed source supplies a matched-resolution independent-autoencoder experiment that resolves the F5 observation. Frequency/spatial labels alone do not guarantee complementary damage. This gap is a limit of this search, not a proof that such work is absent.

JUDGMENT — PROPOSED: No replacement architecture is presently warranted. Carry forward a detector-diversity hypothesis with controlled FPR, plus a write-order/scale diagnosis. Do not adopt a new reference-free instance descriptor, train a network, rewrite F6, or treat self-recovery as content-binding security. **Proposed literature conclusion: KEEP current K08 implementation; UNKNOWN whether a calibrated reader improvement preserves T4/T5.** Confidence is moderate in the decomposition and low in a positive performance prediction. A matched-FPR development result with preserved binding would change this judgment; carrier detections alone would not.
