## Current mechanism and realistic improvement budget

SOURCE — The [K02 dossier](../../components/K02-content-code.md), with repository code and prior-evidence locators, reports 32 signs from HMAC-derived Rademacher rows. Rows depend on profile key, detector configuration and feature width, not OwnerID. Hard bit generation uses max-absolute scaling and a `1e-9` threshold; F5's continuous projection uses unit normalization. The soft reader searches 2,000 angles and combines `Phi(c_j*p_j*cot(theta))` with a bit-flip mixture, returning `32*theta/pi`. This is a statistical approximation, not an exact CLIP/Rademacher likelihood. Normalization and near-zero thresholds must be retained in any reader diagnostic.

DERIVED — A simple counterexample establishes the limitation without running an experiment: let x=(1,0), y=(1,a), 0<a<1, and w uniform on {−1,+1}². Both projections always have the same sign, so disagreement probability is zero although their angle is arctan(a)>0. The exact angle/pi law therefore does not hold universally for Rademacher rows. Padding with zeros embeds this counterexample in 512 dimensions. It does not show that the approximation is inaccurate on the project's actual dense CLIP vectors; that remains a saved-feature diagnostic.

MEASURED/DERIVED — The existing restricted oracle changes only the content verdict on already decoded words. It is not a ceiling for a rewritten watermark or new feature/code. From the K02 dossier and its linked accounting files:

## Adversarial synthesis and bounded options

DERIVED — A 32-bit output has at most 32 bits of unconditional output entropy, but this does not bound the entropy of a separate secret key. Under *independent uniform* bits, accepting radius r gives random collision probability `2^-32 * sum_{k=0}^r binom(32,k)`; neither independence nor uniform adversarial T5 sampling is established here. Balanced marginals do not establish joint min-entropy. Adding ECC or a fuzzy matching radius can enlarge the accepted content neighborhood. It cannot create an authenticity secret from a publicly known image. Helper-data integrity, the secret/MAC/signature construction, and what is bound remain separate K11 questions.

JUDGMENT — The literature offers mechanisms and failure modes, not evidence of F5 improvement. None of these six papers tests F5's independent-autoencoder regeneration setting, its existing bit transport, T4 copy-paste, or matched adaptive semantic-collision attribution. Retrieval gains therefore cannot fill the zero R1 reader opportunity. Strict quality is the existing PSNR >35 dB, SSIM >.9, LPIPS <.1 requirement; no paper supplies a human invisibility verdict. Reader-only changes leave saved pixels unchanged, but must retain existing eligibility and must not describe unassessed pixels as passing.

The following are **leads for a later authorized saved-development study**, not implemented methods or measured gains. Keep existing q32, descriptors, writer, projection seed and endpoints fixed. No learning from held-out pixels/journals or choosing source partitions/codes by outcomes. If the necessary saved features/read confidences are absent, mark the option unavailable rather than run an encoder. The admissible panel and split must be fixed before fitting; tiny, dependent negative pairs are not a population FPR certificate.
