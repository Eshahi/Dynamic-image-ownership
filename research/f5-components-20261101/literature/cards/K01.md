### K01-SURGERY25 — Q1J

SOURCE — Yi Li, Hualiang Wang, Yiqun Duan, Jiheng Zhang and Xiaomeng Li. **A closer look at the explainability of Contrastive language-image pre-training.** Pattern Recognition 162, article 111409, 2025. DOI [10.1016/j.patcog.2025.111409](https://doi.org/10.1016/j.patcog.2025.111409); [publisher record](https://www.sciencedirect.com/science/article/pii/S003132032500069X), [official project](https://github.com/xmed-lab/CLIP_Surgery). Inspected Section 3 architecture/feature surgery, Sections 4.1–4.5 experiments, pp.3–12, particularly Table 3 p.9 and Table 6/limitations p.12.

SOURCE — Architecture surgery substitutes value–value attention for query–key attention in a parallel path and removes that path's feed-forward operation. The original path/output is preserved. Feature surgery removes components common across image–text category features. Table 3: ViT-B/16 Pascal Context explainability mIoU 15.76 becomes 43.47 with architecture surgery and 46.28 with both surgeries. Multi-label mAP is 47.09 before and after architecture surgery alone, then 52.61 with feature surgery. Section 4.5 explicitly says single-label classification is unchanged. SOURCE — Threat/task: training-free CAM/explainability, open-vocabulary and multi-label tasks; class text features enter feature surgery. No T3 independent-encoder regeneration, ownership copy-paste, or semantic-collision false-positive evaluation. Strict watermark quality/human assessment: MISSING.

JUDGMENT — This directly probes which attention operation contributes background/local noise, but **preserving the global output supplies no change to F5's original global vector**. Pooling the new dense branch would be a new descriptor, not the reported method's demonstrated global-descriptor gain. Subtracting category-common features also needs a specified text/category set, absent from the present image-only K01 input. Foreground emphasis could remove a nuisance under T3 while discarding context that separates two instances or rejecting/accepting a pasted foreground differently under T4. Neither direction is measured here. Dense mIoU gains must not become F5 recovery forecasts.

### K01-INTRAMODAL25 — Q1J

SOURCE — Mario Mallea, Ricardo Ñanculef and Mauricio Araya. **Intramodal consistency in triplet-based cross-modal learning for image retrieval.** Machine Learning 114, article 110, 29 pages, published 28 February 2025. DOI [10.1007/s10994-024-06710-z](https://doi.org/10.1007/s10994-024-06710-z); [publisher full text](https://link.springer.com/article/10.1007/s10994-024-06710-z). Class Q1J via Machine Learning SJR evidence. Artifact INTRAMODAL25 is the final publisher PDF. Inspected Sections 3–6, equations 6–12, experimental setup/main retrieval results pp.6–15 and 19, Appendix A numerical tables pp.20–25, especially Tables 3–6. The qualitative appendix is not used to infer a numerical effect.

SOURCE — Hard-negative cross-modal triplets leave intra-modal similarity orderings underconstrained. Full-HN adds visual/text/structural constraints; a margin formulation adjusts constraints using intra-modal similarities. Experiments use fixed EfficientNetV2-L and MPNET features with learned projections, not a CLIP image backbone. Table 6: MS-COCO 5k image-to-image SPICE nDCG is .609 for HN and .623 for FHN. Table 4: Flickr image-to-image SPICE nDCG .574 becomes .578. The tradeoff remains: Table 5 MS-COCO image-to-text recall@1 is 23.7 for HN versus 18.8 for FHN; Table 3 Flickr corresponding values are 48.2 and 47.3.

SOURCE — Threat/task: caption-supervised semantic image retrieval without image category labels, plus a medical-image case study. No same-source independent-encoder regeneration, watermark, T4 or fixed-FPR T5 test; strict image quality/human visibility MISSING. Training is required.

JUDGMENT — The precise K01 link is that cross-modal alignment does not determine image-to-image geometry. This is useful evidence against equating CLIP's text alignment with stable image binding. However, caption-derived relevance can deliberately treat different instances of the same concept as relevant. Improving that criterion may worsen ownership specificity. The small retrieval improvement and cross-modal loss show an actual tradeoff; they do not license an instance-preserving descriptor or a training-free drop-in replacement. F5's keyed projection, carrier and attribution rules are absent from this study.

### K01-SOBER24 — TOP

SOURCE — Qizhou Wang, Yong Lin, Yongqiang Chen, Ludwig Schmidt, Bo Han and Tong Zhang. **A Sober Look at the Robustness of CLIPs to Spurious Features.** Advances in Neural Information Processing Systems 37, 2024, [official proceedings record](https://papers.nips.cc/paper_files/paper/2024/hash/dd59fad18638714e6c447a3b7b9c4160-Abstract-Conference.html). DERIVED/JUDGMENT — The theorem is a counterexample to unconditional robustness from the CLIP objective, **not** an impossibility theorem for all nonlinear CLIP representations, all fine-tuning, or F5. Empirically, the model-selected benchmark cannot estimate the prevalence of failure on an unselected population. The concrete K01 relevance is that its full/mirror/crop average changes background weighting, and apparently strong semantic robustness does not show that those changes preserve instance evidence. This paper supports testing context sensitivity on specified T3/T4/T5 pairs; it does not support removing every background or declaring all CLIP descriptors unusable.

## Adversarial synthesis for F5

SOURCE — [K01 A/B](../../components/K01-semantic-descriptor.md) identifies the actual interface: CLIP ViT-B/32, 512-dimensional unit vectors, full image plus mirror plus four corner crops plus center crop, averaged and renormalized. Crop side is `round(width*7/8)`, assuming the canonical square input. It costs seven forwards per image shared across owner calls; it is neither seven tests nor a maximum-over-views selector. The source descriptor is computed from original pixels; standalone detection recomputes from suspect pixels. A supplied original feature in writer self-verification does not prove re-extraction from the final mark succeeded.

DERIVED — Let `u_i(x)` be unit view vectors, fixed nonnegative weights sum to one, `s(x)=sum_i w_i u_i(x)` and `f(x)=s(x)/||s(x)||`. Away from `s=0`, first-order perturbation is `delta f ≈ (I-f f^T) delta s / ||s||`. Correlated crops do not justify an independent-sample `sqrt(7)` variance reduction; strong disagreement can shrink `||s||` and amplify the normalized perturbation. This algebra identifies diagnostics, not a measured F5 failure or proof that averaging is harmful. Fixed view weights also differ from an outcome-selected best view, whose decision rule/multiplicity would require separate analysis.

DERIVED — Invariance and instance specificity conflict **when the chosen invariant transformation maps two objects that the ownership task must distinguish into the same descriptor orbit**. This is a conditional statement, not a proof that every useful semantic descriptor must fail. A model can preserve information not removed by its invariance. INTRAMODAL25 establishes a concrete cross-modal/intra-modal objective mismatch; ICDIFF24's semantic false positives show that even training specifically for generative replication does not eliminate the negative-pair problem. Neither source establishes a universal impossibility bound.
