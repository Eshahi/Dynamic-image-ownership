# C02 — Sequential spatial/frequency allocation inside a fixed reader layout

The shared data, endpoint and cost definitions in [the author bundle](../ideas/sheets-writers.md) are part of this sheet. Final selection is in [the candidate table](../05-candidate-table.md).


**Class, point, provenance and benefit.** R-full, P2; RT03/RO03/RS07. Outside analogy: chip placement with interference and scarce resources. Potential direct defensive efficacy and article mechanism evidence. A source-conditioned one-shot mask is a separate bandit/supervised simplification, not sequential RL.

**State/action/transition/reward/horizon.** State contains four fixed carrier-group statistics, current residual, decoded margins, gradient conflicts and three measured quality slacks. At each of two allocation stages choose one of four groups for the next half-budget gradient block; updates change residual and the value of the second choice. Sixteen ordered paths result. Keep existing bit locations/code derivation/readout fixed; allocate energy, not secret new locations. Reward is terminal native C/J subject to Q, with a hard final feasibility veto; intermediate slack is not a certificate. Longer horizons are outside this bounded candidate.

**Information and leakage.** Training may observe registered source-model surrogate responses and training-only T3/T4/T5 counterexamples. Deployment sees the clean source and its own writer trajectory, not an excluded family or post-publication attack. Any content-sensitive Jacobian/probe costs are charged to every comparator. D excludes all current P/S/B/reserve/C pools. Moving bits or teaching the reader a new layout would be a separately named new method with metadata overhead, not this fixed-reader allocation.

**Evidence/conditions.** N1 discrete groups and N2 action-dependent residual state are structurally supported by the writer gradient loop (WP1 D03/D04). A half-budget block changes later gradients; useful long-range interaction is UNTESTED. N3 differential group response, N4 reward alignment, N5 amortization, N6 transfer and N7 feasibility remain open. WP3's source-dominated F5 variance is not evidence for controllable allocation. The historical killed texture-mask family weakens an unqualified saliency story but does not logically exclude every registered grouping.

**Strongest fair alternatives.** Enumerate all 16 paths on the small screen; compare uniform allocation, fixed saliency, tuned projected-gradient continuous masks projected into the allowed group actions, greedy coordinate allocation/water-filling and a supervised source-to-path selector. Random ordered allocation is mandatory. A practical full study compares the same discrete actions with beam/dynamic-programming search or budgeted BO, not merely uniform masking. Charge gradient, quality, Jacobian and fitting calls, and allow the non-RL optimizer the policy's training budget.

**Effect/claim target.** No measured effect estimate. Smallest worthwhile direct effect: +10 pp primary-cell C over the strongest non-RL at equal total budget, J non-regression, every final image strictly feasible and preserved T4/T5/C0/wrong-owner behavior. One publishable claim would isolate an order-dependent carrier-allocation interaction that a matched continuous/discrete optimizer misses; “RL chooses image blocks” is occupied.

**First decisive falsification and kill.** Twelve D sources × (16 ordered paths + uniform + saliency + projected-gradient control)=19 terminal paths, two cells, three seeds. The complete finite path table permits random, fixed and supervised/oracle comparisons without free additional paths. **228 writes, 1,368 marked T3, 72 C0, 1,368 extra wrong-owner, 228 clean checks, 456 T4/T5 units.** Kill this bounded layout if no feasible path attains a worthwhile oracle margin over the strongest non-RL, if apparent order differences disappear after equal gradient counts/saved-RGB8 finalization, or if gains need a changed decoder. This can refute the reachable-set/interaction hypothesis; it cannot establish learned-RL superiority. Surviving oracle headroom requires prospective learned and shuffled-state policies later.
