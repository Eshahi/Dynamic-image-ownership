# C11 — Separate removal and forgery players in a vector-payoff population game

The shared data, endpoint and cost definitions in [the author bundle](../ideas/sheets-security.md) are part of this sheet. Final selection is in [the candidate table](../05-candidate-table.md).


**Class / point / origins / analogy:** R-game; P7/D22 with P2/P3 writer responses; RT15, RS04, RO12. Outside analogy: game-playing populations retaining strategically distinct opponents rather than only the latest champion.

**Benefit type:** Potential direct defensive efficacy, security discovery and article evidence. WP6 A2 is applicable only to an actually learned writer response that improves genuine T3 C/J over the best matched non-RL method while preserving T4/T5, strict quality and negative controls; discovering an attack or solving a static mixture does not qualify.

**State/action/transition/horizon/reward:** State is a training-only population of compatible writers and separate T3 removal, T4 forgery and T5 unmodified-selection adversaries, their observed payoff vectors and remaining budget. Add a bounded learned response or change the sampling mixture; three population rounds are the initial horizon. Writer responses select low-dimensional surrogate/update actions and create new marks; attacker responses use the C08/C09/C10-type declared action sets. Payoffs retain C/J, donor false attribution, T5 false attribution, strict-quality violations and resources separately; no scalar averaging may compensate a binding failure with retention.

**Information/leakage:** Writer sees the clean training source, public payload and allowed surrogate responses, never its future attack. Attackers see published carriers and a fixed declared Q>0 interface, with exact donor q/h and identity labels confined to fit rewards/evaluator. Freeze players before source-disjoint evaluation and train fresh exploiters against every method equally. No frozen F6 changes/outcomes, protected data or repeated excluded-family selection. Registry players, if added later, must be separately named with side information and cost.

**Necessary conditions:** N2 strategic response changes the next training distribution; N1 discrete response/mixture choices exist. N7 secure feasible responses and N4 useful vector reward are unknown; N5 amortization, N6 cross-family structure and N8 equal cost remain obligations. WP3 and the retained binding/quality distinctions support a bottleneck question, not observed strategic cycling or a response advantage.

**Strongest equal-total-budget non-RL:** Exact constrained finite-game/LP solution on the shared initial matrix; double oracle with non-RL constrained PGD/expected-loss writer responses and beam/NES attack responses; fixed diverse robust training over all accumulated attacks. Uniform random opponent allocation is mandatory. Each receives the same sources, initial strategies, gradients, feedback, total writes, response-training/tuning/evaluation resources and deploy count. A learned meta-solver merely reproducing the finite solution is not RL benefit.

**Fresh data:** [Fresh-data contract](../ideas/fresh-data-contract.md),96 licensed groups split48 fit/16 selection/32 evaluation, including independently frozen donor/recipient and unmodified T5 challenge groups; custodian excludes all P/S/B/reserve/C and consumed pools by ID/hash, then related groups stay together. No protected identities are opened now; missing distinctness labels or sufficient groups cause DATA_UNAVAILABLE.

**Security/fidelity:** Fixed F5 reader/q32+h32 remains the primary contract; external presence is a diagnostic, not C/J. All writer outputs meet strict clean quality individually. T4 requires exact donor q/record plus acceptance, h separately; T5 targets remain unchanged; C0/wrong-owner A and missingness stay in the payoff audit. Attacker fidelity is separately constrained. Adaptive Q>0/composed attacks are prospective threat expansions; finite-game equilibrium certifies neither original broad security nor unseen attack classes.

**First decisive falsification / kill:** Three pipelines—learned population response, strongest non-RL robust/double-oracle response, and random allocation—each get256 newly written training/selection/evaluation candidates, including three training seeds. Require at least four extra source-majority C/J successes among32 evaluation groups on the prespecified worst cell, no new T4/T5/negative/quality failures, and a learned response outside the initial finite library that survives fresh matched exploiters. Kill if the fixed matrix solution matches it, response cycling merely overfits known opponents, or security constraints are traded away.
