# C01 — Contextual selection from a genuinely new writer menu

The shared data, endpoint and cost definitions in [the author bundle](../ideas/sheets-writers.md) are part of this sheet. Final selection is in [the candidate table](../05-candidate-table.md).


**Class, point, provenance and benefit.** R-bandit, P1; raw RT01/RO02. Outside analogy: instance-specific algorithm portfolios. Possible direct defensive efficacy and article evidence; reduced exploratory writing is a separate efficiency endpoint. A one-shot choice is not a long-horizon MDP.

**State/action/transition/reward/horizon.** Source-only colour/spectral summaries, public owner/profile, declared threat mixture and cost limit form context. Choose one of eight prospectively registered configurations: four feasible quality-budget levels × two fixed carrier-weight templates, all inside the same reader layout. Freeze exact numerical templates before acquisition; no configuration is selected from F6 outcomes. One choice produces a completed mark; future source contexts are exogenous. Training feedback is terminal C/J plus hard Q feasibility and separately logged cost; deployment horizon is one action. A delayed return from later optional native checks is training feedback, not a hidden future-attack oracle.

**Information and leakage.** Learn from fresh fit-source action feedback. Clean candidate-write margins used in WP3 are unavailable before marking unless their entire write/read cost is paid; the primary selector excludes them. At deployment there is no actual future family/strength label. A known service profile may be an explicitly declared input supplied equally to all methods. Stored retained outcomes only motivate this hypothesis; they do not train it. Apply D, including all P/S/B/reserve/C exclusions.

**Evidence/conditions.** G1's structural premise is N1: discrete writer IDs have no pathwise derivative. N3 differential action predictability and N5 amortization remain unproved; N4/N6/N7/N8 remain obligations. MEASURED/DERIVED WP3: retained F5/v5 cell-known C is 275/420, source-and-cell oracle 276/420; J is 130 versus 132. Without cell knowledge, per-source C is 209 versus the best global fixed arm's 196, but that is hindsight and does not improve worst-family C. Thus the retained menu is a near-ceiling **COMPARATOR/ARTICLE-ONLY** subcase, not evidence for a profitable selector. A new eight-action menu is an unmeasured hypothesis.

**Strongest fair alternatives.** Best fixed configuration selected by the existing Stage-P-style racing rule; constrained contextual regression predicting all observed action values; supervised cost-sensitive selection when full information exists; finite-grid/BO acquisition with the same partial feedback; tuned PGD within each configuration. Include uniform random configuration and greedy contextual selection. Equalize feature extraction, writes, native observations, source split and all tuning costs. Replay of a complete table cannot be advertised as real partial-feedback savings unless the information withheld and charged is explicit.

**Effect/claim target.** JUDGMENT: no defensible numerical gain forecast. Smallest worthwhile full-study direct effect is **+10 percentage points source-majority C on the registered primary cell over the strongest equal-budget non-RL**, J non-regression and complete Q preservation. A 10 pp claim is not licensed by a handful of pilot sources. One publishable claim, if supported: a newly measured context–configuration interaction predicts a secure operating point beyond a matched supervised/racing portfolio, with the deployment horizon and cost crossover stated. A matched null is useful evidence, not a new RL algorithm.

**First decisive falsification and kill.** On 24 D sources, write all eight fixed configurations once, evaluate both cells × three seeds, and make the full feasible action table. Compare oracle, fixed, random and source-disjoint supervised selection; gradients/racing tune only inside the same eight-action menu. **192 writes, 1,152 marked T3, 144 C0, 1,152 extra wrong-owner, 192 clean and 384 T4/T5 calls** are covered by B. This is an action-headroom test, **not trained RL efficacy**. Kill this bounded menu if its hindsight feasible C oracle cannot exceed its strongest fixed action by the worthwhile threshold, if improvements require forbidden post-mark information, or if Q fails; a larger menu would be a new candidate, not an automatic retry. Surviving headroom alone does not demonstrate N3.

**Cost and later evidence.** B(24,8,122)=**12.75 h/$7.03**, conditional on retaining the F5 work envelope; altered-template overhead is unmeasured and charged to the 20 h cap. This bounded fixed-menu calculation supports F=3 for an F5-complexity menu only. Substituting F6's unmeasured anchors gives **28.68–52.82 h/$15.80–29.10: EXPENSIVE** and lowers that variant's F to 1; it is not this score's first test. Full-bandit evidence could cache 120×8=960 fit marks (32.53 h writing alone at F5), but all policy seeds/tuning and training feedback are charged. Add L's 39.90 h check stage and at least the actual tuning inventory; no complete <=20 h efficacy study is claimed.

**Three closest inspected works.** [JEC-RL, §§III-B/C, Tables I/IV](https://arxiv.org/pdf/2105.03867) already learns image-dependent embedding costs; JPEG steganalysis evasion is not content-bound T3 survival. [Contextual Bandit Bake-off, §§2.1–2.3, §4, Tables 1–2](https://arxiv.org/pdf/1802.04064) establishes serious greedy/regression controls, with simulated bandit feedback rather than watermark costs. [AdaptiveISP, §§3.1–3.3, §4, Tables 1/3/4](https://arxiv.org/html/2410.22939v1) already conditions processing and runtime on the image; detection accuracy is not strict source preservation or T4/T5 security. Local inspected cards: C01-02, C07-02, C07-08. Unrecovered SPAR-RL/HFRW/KAIST leads still prevent a first-policy watermark claim.

**TD03 comparison.** I01 already searches a fixed-reader writer operating point; I11 already considers channel/constraint interaction. The only residual here is differential source-dependent selection and its equal-cost evidence, not a new robust writer or new Stage P.

**Steelman.** A single fixed configuration could waste quality slack on easy sources while failing others. If cheap source features predict opposing configuration advantages, shared partial-feedback learning could amortize across many publications without repeated deployment writes.

**Hostile reviewer.** The only measured menu has almost no conditional headroom, and the saved predictors use costly post-write information. The proposed eight new configurations might merely reveal a better global setting. A supervised selector is the natural winner with a complete training table; bandit terminology does not earn credit.

**Screens/verdict.** G1 PASS (discrete action); G2 PASS (specified strong equal-budget controls); G3 PASS (D, blind/frozen F6); G4 PASS only for the bounded interaction/null claim, with unresolved prior-art risk; G5 PASS (fixed reader, Q, declared information). Provisional **WATCHLIST**: numerical threshold fails and E is analogy/unmeasured new-menu response; M=2 reflects genuine partial feedback, N=1 narrow residual novelty, F=3 the grounded F5-menu bound, V=2 useful bounded selection evidence.
