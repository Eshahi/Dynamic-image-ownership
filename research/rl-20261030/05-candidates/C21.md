# C21 — Joint discrete sender/reader protocol under separate forgery challenges

The shared data, endpoint and cost definitions in [the author bundle](../ideas/sheets-systems.md) are part of this sheet. Final selection is in [the candidate table](../05-candidate-table.md).


**Class / points / raw IDs / analogy.** R-game, P1/P2/P9/P5; RT19, RS18. Outside analogy: cooperative communication with an interfering channel and a separately adversarial forger. RS18 contributes sequential feature acquisition before committing a deterministic content code; it cannot authorize attack-selected easy payloads. Benefit type: possible direct defense and article evidence, with a fundamentally new carrier/reader.

**Mechanism and observability.** Sender observes clean source, a mandatory original owner/content payload and remaining source-quality budget; selects discrete code atoms and optionally a bounded feature-acquisition sequence before a public deterministic code-commit rule. Receiver observes only the transmitted image and declared public/key information, acquires allowed measurements and decodes. A separate attacker sees published carriers/public code and its explicitly fixed Q=0 or charged Q>0 interface; T3 removal, T4 donor-attribution and T5 collision payoffs remain separate. The sender/reader share correct exact-payload and binding reward, constrained by clean quality; attacker rewards are not blended into a mean that trades away T4/T5. Transition changes partial code, final pixels, then channel observations; sender horizon eight code blocks, receiver four acquisitions. Selection metadata must be decodable without circularly knowing the payload. All public identifiers remain unauthenticated unless an actual declared key/signature system and its bits are added equally to comparators.

**Training/deployment information and leakage.** Offline native-channel calls and forgery labels train policies; deployment receives neither regenerator identity, clean reference, true message nor evaluation negatives unless a separately named side-information arm grants them equally. Mandatory q/h or a newly defined fixed semantic code cannot be retrospectively chosen for survival. A changed content-feature extractor changes the binding task and must be tested on operationally distinct near-copies. Freeze source groups, messages, owner conditioning, channel families and policy before calibration. Message-held-out and source-held-out evaluation are both necessary; new seeds in seen families are not new-family evidence. Joint reader training, calibration and their actual GPU costs are **unmeasured**. F5 FPR cannot transfer.

**Strongest equal-total-budget alternatives.** Differentiable communication autoencoder with the same discrete interface evaluated after quantization (straight-through/relaxation training); supervised codebook/receiver learning with teacher-generated labels charged; fixed ECC/codebook with standard adversarial training; exhaustive search over the same deliberately small code-atom dictionary; random sender/action allocation. Include a random/greedy receiver policy and fixed adversary curriculum, plus exact finite-game best responses where the menu permits them. All methods get the same source/message/negative examples, channel calls, feature capacity, model access and complete training+tuning+evaluation+deployment cost. Fixed F5/VINE are task-context comparators, not substitutes for these equal-payload learned baselines. A neural RL win over only frozen F5 would not isolate RL.

**Necessary-condition evidence / effect.** N1 is supported by discrete protocol symbols; N2 by partial-message/state changes, and the game has distinct observations and feasible finite actions. SOURCE WP4: the failed fixed-reader writer does not prove an empty feasible set, while VINE shows survival using a different reader/payload/quality operating point. Neither identifies a strict-quality, binding-secure joint protocol. N4/N5/N6/N7 remain open. JUDGMENT prospective worthwhile effect: >=10-point source-majority J gain over the strongest equal-budget jointly trained non-RL method in at least two predeclared foreign cells, no >5-point loss in any declared cell, and no accepted clean-quality or T4/T5/negative regression. This is an aspirational decision threshold, not an expected effect or probability.

**Fresh data and hard endpoints.** F must deliver a genuinely new licensed training corpus, initially72 independent groups for a bounded feasibility falsification and much larger disjoint training later if required. The72 split24 train/24 calibrate/24 locked groups cannot substantiate large-model generalization; split messages and near-copy groups too. Clean final source-relative PSNR >35, SSIM >.9, LPIPS <.1 is hard, including all failed attempts. Report C and J analogues with exact definitions, exact mandatory q/h/pointer recovery, coverage, C0/wrong-owner and separate T4/T5. Presence and bit accuracy are auxiliary. New learned feature/reader null validity is unidentified; no cryptographic attribution or rare-FPR guarantee is promised. G5 is unknown until a coherent calibrated decision rule exists beyond a training reward.

**First decisive falsification inventory.** Five equal-access method families above, three independent training runs each, each capped at1000 native feedback calls:15,000 training calls, allocating tuning and failures inside that budget rather than adding hidden trials. Evaluating72 groups×5 methods×3 training runs gives1080 final marks and12,960 native C1 outcomes at four cells/three seeds, plus864 shared C0 native images; every method/seed still incurs its own C0 reader decisions,12,960 wrong-owner reads,1080 clean checks and2160 T4/T5 pairs. Random and fixed-code methods may spend their equal budget on search/validation rather than pretend to train unnecessarily. The genuinely strongest trained comparator cannot be omitted to fit a preferred ceiling.

Wrong-owner+clean+T4/T5 using old read proxies add7.785h;864 C0 native outputs and the different reader evaluations add further cost. If each final mark required an F5-style write,1080×122 seconds adds36.600h; a learned sender may be faster, but its time is unmeasured and cannot be assumed zero. **EXPENSIVE: no credible completed <=20h decisive test.** Report `T_first >=24.794–35.978h + C0/new-reader/write/training overhead`, a conditional accounting range, not a measured lower bound for a different architecture; USD .551 times actual hours. A20h stop can only yield RESOURCE_STOP, not a policy verdict. Kill the bounded route if no common strict-quality packet is feasible, if held-source/message improvement disappears against pathwise/supervised training, if only presence improves, or if forgery negatives worsen. **Later full study / cache.** Five method families×five training runs×10,000 charged channel calls gives250,000 feedback calls alone:152.083–252.083h ($83.80–$138.90 at the retained rate), before sender/reader training and evaluation. At1000 fresh evaluation groups the paired five-method/five-run evaluation has25,000 marks and300,000 marked native outputs:182.500–302.500 feedback hours plus `25,000×w_new/3600` writing hours, new-reader controls and training. At the F5 anchor alone that write term is847.222h, a sensitivity illustration rather than predicted learned-sender cost. Total training remains unidentified; report formulas, not an invented cheap neural implementation. Fixed outputs can be cached only after a sender checkpoint is frozen; every updated sender/payload/code requires new output and channel feedback.

**Closest three inspected works and residual claim.** [Hidden in Plain Text, §§3.3–5.2/Table1](https://arxiv.org/html/2410.03768) already learns communicating sender/receiver strategies through a paraphraser and exposes monitor reward hacking; it is a text task. [SemBind, §§3–4 and Appendices D/E](https://arxiv.org/html/2601.20310v1) already provides semantic watermark binding and adaptive forgery tests, with a different image-generation contract. [SPARED, Method/Eqs.1–3 and Table3](https://arxiv.org/html/2608.12876v1) already alternates an RL detector and diffusion editor; generic adversarial co-training is occupied. TD03 I02/I04/I09/I12 already cover bound carriers, latent insertion, exact payload and ambiguity. The residual would require a concrete discrete protocol mechanism and matched-cost secure communication benefit, not first joint learning or first robust binding. Close inaccessible image-RL work and unsearched learned-coding neighbors prevent novelty clearance.

**Publishable claim, conditional.** A precisely specified post-hoc discrete sender/reader protocol preserves the same mandatory content payload across named native channels at strict source fidelity while rejecting defined forgeries, and RL adds reproducible value beyond equally trained differentiable/supervised protocols. Until those controls and validity exist, this is a broad research program, not a ready article contribution.

**Steelman.** If the current bottleneck is representation/reader mismatch, a jointly trained protocol can change what information is recoverable rather than merely optimize an inadequate fixed score. Discrete native feedback offers a legitimate reason to consider policy learning where exact pathwise derivatives are unavailable.

**Hostile assessment.** Nearly every component changes, so a win can come from reader capacity, training data, a new loss or privileged feedback rather than RL. The reward may learn a transferable owner token that is easy to copy, and an easy content code can conceal loss of instance binding. The costs are orders above a cached finite-menu test, with no project evidence that the mandatory secure operating point exists.
