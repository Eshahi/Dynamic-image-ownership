# C17 — Fixed-payload redundancy and interleaving allocation

The shared data, endpoint and cost definitions in [the author bundle](../ideas/sheets-systems.md) are part of this sheet. Final selection is in [the candidate table](../05-candidate-table.md).


**Class / points / raw IDs / analogy.** Primarily R-bandit, P1/P2/P9; RT04, RS08, RO13. Outside analogy: communication-link rate adaptation and unequal error protection. A single prepublication allocation is horizon one, not R-full; an iterative allocation extension would need an independently demonstrated state benefit. Benefit type: possible direct defense and coding/article evidence.

**Mechanism and contract.** State: permitted source statistics and estimated training-only group-error correlations. Action: choose one of eight fixed redundancy/interleaving profiles for the same mandatory payload; transition creates one final carrier and obtains terminal training-channel feedback. Horizon one. Concrete illustrative packet: original q32, original h32, three profile-signaling bits, and33 parity bits in100 transmitted bits; public claimed-owner conditioning is external side information as in F5, not a signature. All eight profiles must protect the selector or use a predefined jointly decoded profile list whose search is charged. They cannot choose easier q/h after seeing attacks. This is a new packet/decoder contract, not unchanged F5 and not native VINE presence. The exact code family/minimum distance and layout have to be frozen before future acquisition; no distance or authenticity is assumed here.

**Training/deployment information and reward.** Offline training may observe complete prospective source/profile/channel outcomes; deployment sees source features and public profile, without the future regenerator, regenerated output or acknowledgement. Reward is J and separately exact q/h recovery under strict final quality and complete negatives; bit accuracy is auxiliary. Costly clean features requiring a candidate mark must be charged, so they cannot be advertised as free P1 context. Evaluation payload q/h is never handed to the decoder as an answer. A new ECC/reliability decoder has its own measured error assessment; any neural reader training is unmeasured and excluded from the first finite-menu screen.

**Strongest equal-total-budget alternatives.** Best fixed profile, analytic unequal protection under an estimated joint channel, robust/minimax integer allocation, exhaustive eight-profile search, supervised profile prediction from the complete training table, pathwise soft-allocation optimization with final quantized testing, and random profile selection. Same100 slots, payload, selector overhead, writer budget, source access, training+tuning+testing and deployment volume. If RL receives all eight outcomes, supervised learning receives them too. Enlarging the menu only for RL would invalidate attribution. Fixed F5/VINE presence can be context controls, never equal-payload winners by relabeling.

**Necessary-condition evidence / effect.** N1 is supported by discrete coding and layout actions; coding decisions have no ordinary derivative as implemented. WP3 does not identify correlated payload-bit errors or differential profile value, so N3/N4/N7 are unproven. JUDGMENT smallest worthwhile effect: >=4/24 additional source-majority J successes over the strongest fixed profile in at least one foreign cell, no loss in other declared cells, with strict clean quality and no new finite T4/T5/C0/wrong-owner accepts. A later locked study must establish the advantage beyond a supervised selector; this threshold is a falsification target, not an effect estimate or significance claim.

**Data and endpoint gates.** Apply F to24 new groups, using all24 only for a clearly exploratory finite-menu ceiling screen; no policy generalization claim is allowed from that table. Save a separate future source partition for training/calibration/evaluation if headroom survives. All100 bits, parity and metadata are counted. Strict final PSNR >35, SSIM >.9, LPIPS <.1 is measured on saved RGB8 relative to the original; C/J, exact h, T4/T5 and C0/wrong-owner are separate. Quality-ineligible profiles are failures. No rare-FPR or cryptographic guarantee is asserted: new-decoder population error validity remains unknown, but the finite empirical endpoint/access contract is explicit.

First compute the constrained oracle ceiling from this finite table; kill if even the oracle cannot exceed the fixed profile by the prospective margin, if selector errors erase the gain, if strict quality is infeasible, or if coding overhead makes the payload impossible. An oracle win merely licenses a later policy question, not RL efficacy.

Any learned reader adds unmeasured `H_reader`. This full study is EXPENSIVE although a bounded ceiling test may fit20h. Cache each fixed profile once for seed/channel re-use; changing the allocation per rollout requires another122-second write and destroys that saving. Report both cold-start comparison and a fixed future deployment count; theoretical future volume is not observed amortization.

**Closest three inspected works and residual claim.** [MCTSteg, §III and TablesII/VI/VIII](https://arxiv.org/pdf/2103.13689) occupies sequential nonadditive embedding-cost allocation, for hiding rather than ownership. [VINE, §3 and Appendix C](https://arxiv.org/html/2410.18775v2) supplies robust100-bit carrier/presence machinery, without promising arbitrary exact decoding at69/100. [DREW, §§3.2–3.4 and Appendix B](https://arxiv.org/html/2406.02836v2) already uses coding for robust retrieval. TD03 I09 already proposes the verified-payload frontier and I02 carrier binding. The residual is measured conditional allocation benefit under correlated native failures at equal payload/quality, not new ECC or a first RL watermark. Inaccessible SPAR-RL/HFRW-type leads keep image-RL priority unresolved.

**Publishable claim, conditional.** A fixed-payload, fixed-capacity native-regeneration channel has a reproducible profile-by-source interaction, and a specified learned allocation beats analytic/supervised alternatives at equal total cost. A useful null would show that ordinary coding or a universal profile exhausts this opportunity; that is not a new RL method claim.

**Steelman.** Regeneration may create correlated failures that make equal protection wasteful. A small source-conditioned profile could exploit those patterns without repeatedly rewriting a carrier online.

**Hostile assessment.** Eight profiles are cheap to enumerate, and coding theory already attacks this allocation problem. There is no measured joint-error model, feedback from the future channel or proof that100 bits accommodate a useful bound payload. Native VINE's31/60 strict-quality development passes are a warning against assuming clean feasibility. A selector that only saves coding work cannot establish new channel capacity.
