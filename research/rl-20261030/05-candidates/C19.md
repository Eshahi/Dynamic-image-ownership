# C19 — Sequential erasures and exact-payload decoding

The shared data, endpoint and cost definitions in [the author bundle](../ideas/sheets-systems.md) are part of this sheet. Final selection is in [the candidate table](../05-candidate-table.md).


**Class / points / raw IDs / analogy.** R-full, P5/P9; RS09. Outside analogy: reliability-guided error/erasure decoding and sequential communication receivers. Benefit type: possible direct defense through exact decoding, and payload/article evidence; better bit confidence or lower read cost alone is insufficient.

**Mechanism and information.** Use a separately named fixed coded packet such as C17's q32/h32/profile3/parity33 format, frozen before this study and held identical for every decoder. This is a dependent packet choice, not permission to count an undeveloped carrier as ready. State: observed soft bit/chip reliabilities, partial syndromes, measurement history and remaining attempts. Action: acquire one of four fixed permitted measurements, choose a predeclared erasure profile, attempt a unique/list decode, or abstain; horizon at most four measurements and four decode attempts. Transition reveals information or changes the candidate codeword set. Training reward is exact original q and separately q/h, with wrong-code output a hard failure, not a small scalar penalty. At deployment there is no true q/h or clean original. Public claimed owner, packet codebook and selector-signaling rule are declared; a registry/dictionary would be an additional separately named arm, not free information.

**Strongest equal-total-budget alternatives.** Fixed ECC decoding; reliability-ordered erasures; soft-decision/list decoding; exhaustive allowed erasure patterns; dynamic programming/greedy information gain for the same four measurements; supervised mapping from reliabilities to decode policy; random erasures/order; and a state-shuffled policy. Small erasure menus allow finite enumeration. All methods share the packet, soft outputs, source/model access, calibration, list size, number of attempts and full training+tuning+evaluation+deployment budget. Pathwise reliability calibration is permitted and isolated from RL. If all required reliabilities are already available, do not simulate partial observation solely to handicap ordinary decoding.

**Necessary-condition evidence / effect.** N1 supports discrete erasure/list/stop decisions; N2 can hold only if an acquired measurement adds useful information. SOURCE WP1: current F5 already decodes q from fixed segment scores; erasing independent payload bits without parity or new observations cannot reconstruct them. No measured project joint-error or syndrome table establishes the new opportunity. JUDGMENT smallest worthwhile effect: >=10 percentage points more source-majority J than the strongest fixed/list decoder, without more false q/h outputs, lost clean feasibility or T4/T5 accepts; alternatively >=25% total decoding-cost saving at exactly matched outcomes. The alternative is efficiency, not a direct defense gain.

**Data and gates.** F supplies72 fresh groups,24/24/24 fit/calibrate/locked. Freeze carrier and parity construction independently of the evaluation table; use mandatory original q/h, never an easier decoded payload. Final clean PSNR >35, SSIM >.9, LPIPS <.1 and C/J/exact-h/T4/T5/C0/wrong-owner requirements remain. A decode attempt rejected by a checksum is not automatically a calibrated ownership rejection, and extra list attempts change false-acceptance risk. New-reader wrong-decode probability and analytical FPR are **unknown**; finite errors and source-level intervals can be measured, but F5 thresholds cannot be inherited. No neural reader retraining is assumed for the first screen; if needed, training cost is a new unmeasured dependency.

**First decisive falsification / cost / kill.** L72 gives4.010–4.701 core hours and6.642h/$3.66 with reserve/setup. Materialize the same fixed measurement/reliability table for all six decoder families, charging an explicit4h cap for added measurements, fitting, list/erasure enumeration and pair preprocessing: **10.642h/$5.86 conditional cap**. The1.4-second read anchor does not measure extra views; incomplete measurement inventory is RESOURCE_STOP. First test the complete-information correct-decode ceiling against a strong list decoder. Kill if no valid parity packet is feasible, if erasures only abstain on already lost information, if ordinary list decoding reaches that ceiling, or if any gain depends on extra attempts with unaccounted false decoding. This ceiling test can reject the policy route; it does not train a neural decoder or prove rare-error validity.

**Later evidence / cache.** L240 gives19.806h/$10.91; allow12h for larger measurement tables and policy/calibration work, **31.806h/$17.53 conditional**, plus any unmeasured learned-reader training `H_reader`. Exact rare-error assurance needs a separate justified model or much larger null sample. Cache the fixed carrier and native outputs once; decoding variants may reuse the same measurements, with their actual online acquisition and decoding work charged. Never pay for rewrites simply because the receiver tries another erasure pattern. Report deployment volume needed to recoup policy fitting over a cheap algebraic decoder.

**Closest three inspected works and residual claim.** [VINE, §3 and Appendix C](https://arxiv.org/html/2410.18775v2) supplies carrier/presence context, not exact-payload recovery at69/100. [DREW, §§3.2–3.4 and Appendix B](https://arxiv.org/html/2406.02836v2) already combines ECC decoding and fallback retrieval. [MetaSeal, §§5–7 and Appendix C](https://arxiv.org/html/2509.10766v2) already has a content-dependent signed payload and reports regeneration verification failure; a short q/h code is not its authentication task. TD03 I09 directly occupies the exact-payload frontier. These inspected neighbors do not clear novelty against the broader classical learned-decoding literature, which would need a focused follow-up before a method-priority claim.

**Publishable claim, conditional.** Under a fixed native-regeneration channel and packet, extra evidence acquired conditionally improves exact payload recovery beyond strong soft/list decoding at matched global errors and total cost. The likely fallback is a useful payload-recovery ceiling/null, explicitly not a new ECC principle.

**Steelman.** Correlated unreliable groups can make one additional observation valuable only after a first syndrome is seen. A small receiver policy could exploit such asymmetry without any expensive writer exploration at deployment.

**Hostile assessment.** Ordinary reliability-ordered list decoding is built for this task. RL cannot recreate erased bits without redundancy, new measurements or a hidden code dictionary. More decode attempts can inflate false acceptance, and modern carrier presence scores do not identify the required reliability model. Novelty against learned ECC decoding is not cleared.
