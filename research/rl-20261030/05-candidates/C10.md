# C10 — Bandit search over unmodified T5 candidates

The shared data, endpoint and cost definitions in [the author bundle](../ideas/sheets-security.md) are part of this sheet. Final selection is in [the candidate table](../05-candidate-table.md).


**Class / point / origins / analogy:** R-bandit; P6/D19 and P10 retrieval; RT13, RS02. Outside analogy: adaptive retrieval/active testing over a finite pool with partial feedback, not physical sequential image control.

**Benefit type:** Security discovery, query efficiency and article evidence. WP6 A2 is **not applicable by design**; finding collisions does not improve defense.

**State/action/transition/horizon/reward:** State is a claimed donor, public descriptors of128 eligible unmodified candidates and prior permitted replies. Choose an unqueried candidate/neighborhood or stop, Q=16. Transition changes information and remaining pool only; no image is edited. Reward is a valid exact-donor/record false attribution within Q, with query count and distinct candidate groups retained. Similarity or C alone is an auxiliary signal, not the endpoint.

**Information/leakage:** API returns fixed accept/read/declared score fields; evaluator distinct-instance labels and original q/h are never deployment state. Training can use correctly labelled pairs; selection/evaluation use whole disjoint related-image groups. Initial descriptor extraction is charged and cannot secretly include reading all candidates with the target detector. Same pool and observations go to every comparator. No retrospective Phase B/F6 tuning or test-derived semantic neighborhood construction.

**Necessary conditions:** N1 discrete candidate selection is supported; N3 differential neighborhood risk is unknown, and N2 means information acquisition rather than an image MDP. N4 sparse meaningful positives, N5 amortization and N8 fair budget are unresolved. The old0/66 T5 result is limited negative evidence, not an adaptive vulnerability or rare-event certificate; source survival predictors in WP3 do not predict collisions.

**Strongest equal-total-budget non-RL:** Fixed nearest-neighbor ranking, supervised collision-risk ranking with the same fit labels, non-RL adaptive surrogate acquisition/active testing, exhaustive ranking where the budget covers the pool, and stratified random search; a shuffled-reply bandit isolates feedback value. Gradients cannot modify T5 targets; they may rank descriptors only with equally available public models. All descriptor construction, learning, validation and queries are charged.

**Fresh data:** [Fresh-data contract](../ideas/fresh-data-contract.md),36 donor-centered groups split12/8/16 and128 fixed-rule eligible targets per donor before feedback. Licence, hash and duplicate-group exclusion covers P/S/B/reserve/C and consumed pools without opening IDs now. Near-copy challenge sampling and human operational-distinctness labels are independently frozen; absent labels give DATA_UNAVAILABLE. Shared targets link groups and cannot cross partitions.

**Security/fidelity:** Targets stay byte-identical throughout T5 search; editing or regeneration would be a separately labelled expanded/composed attack. Exact donor q/record plus acceptance is primary; h, C/J, P and registry side information remain separate. Clean donor marks obey the strict bar; attack fidelity is trivial for unmodified targets, while operational distinctness still needs evidence. Q>0 search is a prospective expansion of the original Q=0 T5 setting. C0/wrong-owner A controls and T3/T4 reference endpoints are not improved by selection.

**First decisive falsification / kill:** On16 new donor groups require at least three additional true distinct-instance false donor attributions at Q16 over the strongest ranking/acquisition comparator, plus a positive real-versus-shuffled feedback contrast. Kill this learned search if fixed similarity or supervised ranking matches it, all positives depend on missing identity labels, or the required descriptor precomputation already exhausts the query budget. JUDGMENT smallest worthwhile effect is the three-group increment; no collision probability is inferred from old zeros.

**First cost:**36 cached F5 donor writes=1.22h. Six methods×1,400 charged reader opportunities plus1,600 controls/failed-call reserve=10,000; conservative read+quality accounting1.65s gives4.58h, with no native diffusion required. Add4h for public features of up to4,608 targets, fitting across three learner seeds, setup and retrieval:9.80h/USD5.40 planning envelope, cap20h. Feature/training costs are unmeasured and excess is RESOURCE_STOP. **Not EXPENSIVE for this bounded screen.** Native-feedback2.19–3.63s is inapplicable to the unchanged-target calls; F6 donors, if later used, cost3.61–7.23h for36 writes and are not assumed here.

**Later full evidence:**360 donor groups/46,080 targets/100,000 charged reads and tenfold reserve gives about98h/USD54 conditional on feature timing. Query-discovery evidence is not a population FPR estimate; substantially more independent negatives and a separately fixed sampling estimator are required for rare-risk claims. Reusing cached unchanged pixels is valid, but no candidate's hidden target reply may become free policy input.

**Three closest inspected works / delta:** [Soft-binding benchmark §§3.3.4,5.2,6–7](https://arxiv.org/html/2610.04151v1) already studies near-copy retrieval/false matches. [SemBind §§3–4,Appendix D](https://arxiv.org/html/2601.20310v1) occupies semantic binding and adaptive challenges. [Active Testing §§2.2–3.4,5](https://proceedings.mlr.press/v139/kossen21a/kossen21a.pdf) supplies a strong non-RL acquisition framework. Residual is a query-conditioned exact-attribution discovery curve with unmodified candidates and matched training cost; not first adaptive search or first collision.

**TD03 / publishable claim:** I05 covers T5 negatives and I08 query multiplicity; I12 covers ambiguity. Possible claim: “Detector feedback adds measurable value, or none, beyond public semantic ranking for finding unmodified operationally distinct targets falsely attributed to a donor.”

**Steelman:** Weak but structured replies could reveal dangerous neighborhoods after only a few queries. **Hostile:** Positives may be too rare for learning, while public similarity and a supervised scorer already contain nearly all useful information; adapting query order is not automatically an RL contribution or an unbiased risk estimate.

**Screens / provisional verdict:** G1 PASS discrete partial-feedback premise; G2 PASS ranking/acquisition/random alternatives; G3 PASS prospective contract with human labels unresolved; G4 PASS narrow query-value evidence, not generic bandit novelty; G5 PASS unchanged targets and expanded access. WATCHLIST: no project action-value evidence and no established need beyond ranking.
