# Named venues for the forecast exercise

Primary publisher pages reopened 2026-10-30. This file fixes venue names for elicitation; it does not estimate acceptance, certify Q1, recommend submission or authorize fees.

- **IEEE Transactions on Information Forensics and Security (TIFS):** the [official scope](https://signalprocessingsociety.org/publications-resources/ieee-transactions-information-forensics-and-security) includes information forensics and security. [SPS author instructions](https://signalprocessingsociety.org/publications-resources/information-authors), opening contribution/review criteria, require a distinct contribution and sufficient evidence; combining familiar methods can be insufficient. The [deep-learning guidance](https://signalprocessingsociety.org/sites/default/files/uploads/publications_resources/docs/Guidelines__deep_learning_submissions.pdf), pp.1–2, calls for reproducible training, selection and evaluation detail. Its negative-result provision concerns contradiction of published research and has a stronger reproducibility burden; failure of our own writer is not automatically such a contradiction.
- **Pattern Recognition Letters (PRL):** the [publisher's description](https://shop.elsevier.com/journals/pattern-recognition-letters/0167-8655), Description, supports concise methodological or significant application studies with interest beyond the immediate case. A single watermark allocation experiment still needs that wider lesson. Pattern Recognition Letters is distinct from Pattern Recognition.
- **IEEE Access:** the [official submission guidance](https://ieeeaccess.ieee.org/authors/submission-guidelines/), manuscript categories, provides a negative-result route. It still requires a substantive, distinct result; naming this category is not an acceptance promise.

No empirical venue acceptance-rate reference class is available. Forecasters must not borrow an unsourced publisher-wide percentage or call their estimates calibrated. Exact current JCR/SJR year/category status remains unresolved here; WP7 will verify it where accessible or report UNKNOWN. Acceptance in a named journal does not automatically meet an unspecified Q1 requirement.

Source hygiene: a search also surfaced `sciencedirectelsevier.com`, which is not the verified Elsevier domain and displayed inconsistent journal metadata. It is excluded. Secondary crowd estimates of acceptance rates, review times and quartiles are not used.
