## Precisely frozen operators

Keep pinned SD1.5 fp16 assets, DDIM50 schedule981..1, sampler eta0, CFG7.5, post-CFG ordinary predicted-clean calculation, channel0, the existing ordered128 DCT positions in band16..48, seeds1000..1003 and their exact existing prompts. **C-EQ5:** guide only loop indices45,46,47,48,49 (timesteps81,61,41,21,1). Original loss `sum((c_j-.3*y_j)^2)/128` over all128 selected coordinates, gradient as before, eta100. All other steps use the exact old unguided branch.

**C-Q5:** same five indices, eta100 and normalization128. At each guided step, for bit b and its eight ordered coefficients c_j, let y_b=+1 for payload1 and -1 for0. Compute `v_j=max(0, .3-y_b*c_j)` and costs `v_j^2`. Select exactly five members with smallest costs, breaking ties by the existing within-group position index0..7. Define `L=sum_b sum_(j in selected-five) v_j^2 /128`. The selected set is recomputed solely from that arm's current ordinary predicted-clean coefficients, never C0, a decoded image, evaluation reference or a detector result. Its piecewise gradient in coefficient space is `-2*y_b*v_j/128` for selected members, zero otherwise; use the DCT adjoint for the channel0 spatial gradient and `corrected=ordinary-100*gradient`. Freeze the chosen set during each gradient calculation. At exact cost ties this is the declared deterministic piecewise subgradient, not a claim of global differentiability.

The five nearest halfspace projections minimize Euclidean coefficient displacement to the union of regions having at least five coefficients with signed margin>=.3 in each group. Eta64 would project exactly in an isolated clean-coefficient calculation; it is **not** this run. Eta100 overshoots a violated boundary by factor.5625 of the residual while leaving already satisfied coefficients unchanged. Subsequent DDIM transport/denoising can change these margins, so no endpoint vote guarantee is inferred from that isolated algebra. Using five for both payload signs avoids exploiting the zero tie convention during embedding.

The eligible detector remains blind: one VAE posterior-mode encoder, scaled latent, channel0 orthonormal DCT and strict `c>0`, then >4 positive votes. It receives neither selected-five indices, prompt, seed, C0, terminal latent nor generation traces. The original image-DCT readout remains diagnostic only. Both intended/original/complement matches must be retained. The embedding mask's current five-vote selections are instrumentation, not detector side information.
