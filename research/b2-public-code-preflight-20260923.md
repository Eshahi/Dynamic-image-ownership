## ZoDiac targeted pinned code trace (additional read-only inspection)

The pinned [README](https://github.com/zhanglijun95/ZoDiac/blob/89f864d2e4f6f33663dc69b4d99bee49073e194c/README.md) instructs `conda env create -f environment.yml` and a notebook demonstration; the actual tree has lowercase [`example.ipynb`](https://github.com/zhanglijun95/ZoDiac/blob/89f864d2e4f6f33663dc69b4d99bee49073e194c/example.ipynb), not a single reproducible scientific CLI command. Its example config chooses `stabilityai/stable-diffusion-2-1-base`, 100 latent-optimization iterations, watermark seed 10, a 0.92 SSIM postprocess target and 0.9 detection threshold. These are **upstream example settings**, not adopted A4 thresholds or fair matched conditions. The notebook reads `example/input/pepper.tiff`, uses `WMDetectStableDiffusionPipeline` with `DDIMScheduler`, inverts the existing image, optimizes its initial latent with Adam and 50-step denoising, saves a PNG, then calls `watermark_prob` on the suspect image. The pinned [`main/utils.py`](https://github.com/zhanglijun95/ZoDiac/blob/89f864d2e4f6f33663dc69b4d99bee49073e194c/main/utils.py) detector VAE-encodes that image, runs 50-step forward diffusion, and applies `GTWatermark.tree_ring_p_value` in [`main/wmpatch.py`](https://github.com/zhanglijun95/ZoDiac/blob/89f864d2e4f6f33663dc69b4d99bee49073e194c/main/wmpatch.py). The example passes an empty tester prompt; this is an observed example access profile, not proof of every paper setting. No owner or source image is passed to that detector function, but it does receive the diffusion model, text embeddings and watermark pattern object; it cannot be equated with A5's OwnerID verifier.

The pinned [`environment.yml`](https://github.com/zhanglijun95/ZoDiac/blob/89f864d2e4f6f33663dc69b4d99bee49073e194c/environment.yml) is Linux/CUDA-oriented (Python 3.10.13, PyTorch 1.13.1/CUDA 11.7, Diffusers 0.21.4, Transformers 4.37.2, Datasets 2.14.6). Its direct conda recreation is not a Windows 5070 Ti compatibility result. The notebook also includes attack and dataset-loading cells; executing the whole notebook would be a scientific/network-capable run, not a harmless probe.
