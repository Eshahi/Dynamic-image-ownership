# B-LW1-P1 independent readout implementation

`scripts/m1_gs_lightweight_probe.py`, version `m1-gs-lightweight-positive-probe-v1`, implements the prospective probe in [the frozen diagnosis](m1-gs-lightweight-positive-diagnosis.md). It changes neither GS generation nor the original LW readout. No GPU run has been performed for this implementation note.

The manifest locks the exact positive LW run/conditions hashes. Preparation checks its complete output receipts, its native source receipts, every native completed-file receipt, native commit/manifest and all 24 selected PNG hashes. It copies the fixed four cases × C0/C1 × clean/VAE/.4-seed0 to hash-sorted opaque filenames. Preparation opens bytes for hashing/copying, not images for scoring. A separate Windows Job-contained worker receives only sealed opaque paths/hashes, four nonce candidates, public key bytes and the fixed processor configuration. The evaluator map contains original labels, old votes and references, and is opened only after that process exits. This is a reviewable data-flow boundary, not an adversarial filesystem sandbox; nonce bytes remain public and arbitrary code could enumerate the public four-seed fixture.

The only model loaded is pinned fp16 SD1.5 AutoencoderKL: one posterior-mode encode per PNG, followed by fp16 .18215 scaling. Network calls are blocked. No U-Net, text encoder, diffusion inversion or image generation is invoked. Original saved model outputs retain their source safety provenance. No fresh decoded model image is produced, so no new safety-checker execution is needed. Asset receipts and processor module hash/config are recorded. The worker emits float32 copies of its scaled fp16 latents, binary signs and hashes; it also records unscaled/scaled zeros, sign changes, allocation and timings. Correct/wrong SHAKE whitening and all 256 votes are computed by explicit `(c,a+8r,b+8s)` loops, without importing either GS decoder or evaluator.

The evaluator recomputes every emitted query from retained raw bytes and checks exact old correct/wrong votes, bits and matches. It reports all 72 foreign-nonce scores, 24 one-column alignment controls and floating negation controls. Zero coordinates remain zero under strict `>0`; their signed whitening contributions adjust `64-v` explicitly. Nonzero, non-tied bits complement algebraically. References are used only for scoring after extraction. Source marked noise is reconstructed only in this phase, checked against the original fp16 tensor self-check hash, and compared with each latent alongside all paired/foreign Gaussian and marked noises. Cosine/sign agreement have no fitted decision threshold.

All 24 planned conditions survive startup failure, timeout and missing/failed readouts. Detailed assessment rows preserve failures; an incomplete probe has null gates. A completed experiment may have a false implementation gate: completion is not success. The gate requires exact replication, zero-aware algebra, runtime synthetic arithmetic checks, all four source-noise self-checks, and every foreign/shift control below the predeclared 180/256 cutoff. The controls are correlated engineering diagnostics, not population FPR or authenticated ownership. Human verdicts remain null.

The owned worker has a 120-second parent deadline and kill-on-close Job containment. Its allocation cap is 10 GiB; output cap is 100 MiB, checked during work and at finalization. Metadata and evaluator CPU time are recorded in overall duration; the hard deadline bounds the worker rather than forcibly interrupting synchronous provenance hashing or final reporting. No resumption is offered for this bounded 24-image probe: use a fresh directory and retain any failed attempt.

CPU verification: ten procedural unit tests cover documented SHAKE bytes, exact known-message recovery, a specifically located one-coordinate vote change, all-bit ties decoding zero, nonzero complement, explicit zero exceptions, malformed scores, sealed leakage/duplicates/subsets, source-noise magnitude pairing, reference-independent output arrays, and preservation of all 24 failed rows with null gates after a stopped worker. Metadata-only preparation on the fixed retained runs succeeded. These checks do not verify fresh model arithmetic; that remains the parent's committed experiment.

After committing, run with the science interpreter and arguments `--manifest research/m1-gs-lightweight-probe.json --native-dir MAIN/.thesis-build/dev-runs/20261004-0000-gs-native --lightweight-dir MAIN/.thesis-build/dev-runs/20261004-0010-gs-lightweight --output-dir MAIN/.thesis-build/dev-runs/<fresh>-gs-lightweight-probe`, expanding MAIN to its absolute path. Outputs are `run.json`, sealed input, evaluator map, copied source receipts, worker ownership/log, `readout/run.json`, `readout/rows.jsonl`, raw tensors and `assessment.json`.
