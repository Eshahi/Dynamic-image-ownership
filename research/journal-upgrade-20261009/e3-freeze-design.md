# E3 generative freeze and payload-supplier boundary

2026-10-10. Codex method-design escalation, gpt-6-astra/high. Design deliverable only; not an independent review, gate verdict, experiment authorization record or claim of fresh-writer validation.

## Decision

Freeze measured E3-BCH59-Q080 as the partial operator **`embed(x, alpha, q, h; frozen_config)`**, with an explicit, separately versioned payload supplier. Here x is canonical 512x512 RGB8, alpha is literally `qim-pilot-owner-alpha`, and q/h are unsigned 32-bit targets fixed before writing. Reject any other owner at this interface. A general OwnerID argument or alpha initializer subsequently adapted to another owner would be a new extension; neither is necessary for the current original-gate scope.

The measured supplier is **historical E3 payload records for twelve development sources only**. `journal_readability_probe.payload` loads old F5 pixels, reads the original embedding report's intended q and obtains h through native F5 clean decoding, checking against frozen discovery rows. h is an operational decoded target, not a demonstrated original embedded h. The old marked pixels do not initialize E1: E1 starts from x. Source IDs and old files supply experimental targets; they must not become a deployment lookup or be silently dropped from the method description.

The operator has a meaningful general input domain without guaranteeing success for arbitrary targets. q depends on source semantics; h depends on the historical F5 bootstrap image and its native q-conditioned read route. Content predicates can reject a perfectly delivered but incompatible pair. No claim that q/h are independent random messages, source-independent IDs, cryptographic ownership credentials or 64 freely usable payload bits follows.

## Exact operator contract

The normative scientific implementation is E1 `journal_bch_probe.py` at 4bbc427, its imported scientific routines, and E3 `quality-conditioned-decision.md`. Preserve their model/profile/config bytes and numerical choices when extracting a callable function; the CPU row composer alone is not an embedding implementation.

1. Construct the E1 BCH pattern for q under alpha and the existing profile/layout. From x run robust PGD at 46 dB for 150 steps, target margin 4 and mask power 0; round to RGB8 and restore the fixed q/h fragile pattern. From that saved result run 52 dB PGD for 50 steps, round and restore the same q/h again. Save/reload RGB8. These two restorations do not recompute h.
2. Qualify that initializer using exact native q/h reads, `both_match`, strict clean PSNR >35 dB, SSIM >.9, LPIPS <.1, and the existing pixel-box/additional/total norm constraints. An invalid initializer skips all refinement and remains the final E1 artifact. It is not a failed process and must still reach E3's quality branch. Exceptions, missing artifacts or cap/OOM interruptions are construction failures instead.
3. For a valid initializer, preserve the twenty-logical-step minimax schedule. Branch order is clean, SD1.5 posterior-mode VAE, SDXL posterior-mode VAE, then SD1.5 DDIM strengths .1/.2 with seeds 0/1/2. Optimize the first maximum-loss branch using its native gradient. The loss is the squared positive score hinge at 9 plus mean squared positive coded-bit gap hinges at 1. Added radius is sqrt(N)*10^(-52/20); total radius about x is sqrt(N)*10^(-35.1/20), N=3*512*512. Preserve `projected_update`, RGB8 rounding and feasibility checks.
4. Try the three existing step fractions (.1,.5,1) for steps 0–9 and (.025,.125,.25) for 10–19. Evaluate all nine losses for every proposal, including an infeasible one. Accept only feasible, clean-qualified proposals reducing maximum loss by at least max(1e-6, 1e-4*current_max); choose lowest maximum, then proposal order. Otherwise retain the current RGB8 state and use only the existing same-phase no-op shortcut. Preserve the exact inactive-hinge shortcut and invalid-gradient stall behavior. No new early stopping, best-checkpoint selection or fragile restoration follows refinement.
5. Let m be that final saved E1 artifact. If its clean quality passes, retain it. Otherwise apply exactly once, channelwise: `d=int32(m)-int32(x); y=uint8(int32(x)+sign(d)*((4*abs(d)+2)//5))`. Selection uses quality only, never detection, source ID, attacked results or target difficulty. Missing/nonfinite metrics cause execution failure, not contraction. Save/reload y, require strict quality and exact supplied q/h with native `both_match`, and return y or a labelled failure with the saved output. A retain-branch payload failure does not trigger contraction. A failed contraction receives no repair, alternative dose, new h, optimization or source replacement.

Keep BCH(59,32), correction radius five, 320 chips, existing carrier domain, RC1 instance routing, soft combined binding, roster size one, semantic thresholds 8.566138863740473/5.386772268905419 and all instance/content thresholds unchanged. Renaming the writer must not alter profile-derived patterns. Decoder inputs remain suspect pixels, public OwnerID/profile, pinned CLIP and SD1.5 encoder. It receives neither x, q/h, source identity, supplier artifacts, clean verdict nor the quality branch. Exact-message assessment uses target side information outside detection. Same-owner reference-specific attribution remains unidentifiable through this source-blind API.

Freeze diffusers 0.35.1 and the existing pinned local model revisions, SDXL VAE revision 6f5909a7e596173e25d4e97b07fd19cdf9611c76, fp16 native DDIM and fp32 reader/SDXL, including existing RGB8 straight-through conventions and checkpointing. Obtain timesteps from `set_timesteps`/`get_timesteps`, asserting two executed steps at .1 and four at .2; do not reinterpret this as twenty executed denoising steps or hand-substitute a schedule. These six channels are training conditions. Evaluation on them is not unseen-channel evidence; official evaluation retains its safety checker.

## Smallest new-source supplier decision

Recommend **E3-S1: fresh frozen-F5 bootstrap**, explicitly a prospective supplier amendment, not already measured E3 equivalence. It best preserves the *meaning* of historical targets without inventing an unrelated h recipe:

- Run the frozen F5 r2 construction once on x under alpha using the actual historical settings from `20261005-0640-f5-gate-soft-views7/run.json`: robust PSNR 52, 150 steps, margin 4, mask power 0, band [4,32], whitening 1, one refinement round, soft binding and seven-view source CLIP. This is **52**, not E1's 46 dB first-stage budget. The internal second robust pass is 58 dB/50 steps; its two fragile passes derive their own F5 hashes as in `f5_latent_codec.embed_rgb`.
- Save/reload the F5 output. Set q to its embedding report's intended semantic word. Re-extract with the frozen native F5 decoder using that saved image's own seven-view CLIP and SD1.5 latent, soft combined binding and roster one. Require both channels to be readable and set h to the native decoded instance word. Do not force the intended q into F5's h route, require exact decoded q, or substitute a clean-source perceptual hash. Those choices differ from the historical supplier. No extra F5 quality or `both_match` filter is introduced.
- Freeze the pair before E3 starts. Return an explicit supplier failure if construction or either native read fails. Do not search over F5 seeds, outputs or payloads. Do not reuse bootstrap pixels as the E1 initializer. Record bootstrap cost and supply provenance separately.

The historical frozen-row equality check is provenance for the old twelve; it has no new-source analogue. Its removal from S1 does not prove that a fresh bootstrap gives the same pair or selected-payload population. S1 is a reproducible rule for new inputs, not a claim that unobserved historical h values have been recovered. Its extra F5 generation is real deployment cost.

## Cost and scope

At minimum E3 writing requires 200 PGD iterations and two fragile restorations. Valid initializers can additionally require twenty gradient updates, up to sixty proposals and nine channel forwards per baseline/proposal, with existing exact shortcuts reducing work. S1 adds another F5 bootstrap of 200 PGD iterations and two fragile writes plus native extraction. This is encoder/diffusion-heavy writing with a source-blind encoder-based detector; cached E3 composition seconds are not embedding latency. Report supplier, initializer, refinement, quality/clean qualification and loading costs separately; retain failures in timing summaries. Existing historical E1 A/B totals include evaluation/startup and are not fresh E3 benchmarks. The prior 4,200-second construction-characterization ceiling is a bounded development allocation, not a runtime guarantee for S1 or all possible valid refinements.
