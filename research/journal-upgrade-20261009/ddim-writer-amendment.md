## Fixed objective

Retain the existing intended-code vectors w and per-bit difference patterns from patterns(profile, q). For branch b, let p_b be its 320 reader projections, sigma_b = max(norm(p_b)/sqrt(320), 1e-8), score_b = dot(w, p_b)/max(norm(p_b), 1e-8), and gap_bj the existing signed intended-bit projection difference divided by sigma_b.

Use the same scale as the preceding objective, without fitting new thresholds:

    L_b = relu(9 - score_b)^2 + mean_j relu(1 - gap_bj)^2
    L = max over all nine branches of L_b

Select the first maximal branch in the declared order and backpropagate that branch only. This is a subgradient of the max where branch losses are differentiable, with the explicit quantization surrogate just disclosed. Every iteration measures all branches before choosing it. Targeting all 32 margins addresses readable one-bit errors; increasing only total score would not do so.

Do not add a newly approximated CLIP/content loss in D1. Intended-q stability is a limited proxy: even exact q can fail the actual semantic-content predicate if regenerated features change. The actual content predicate, including recomputation behavior, is evaluated unchanged in the grid and can kill D1. There is no implication from zero hinge loss to semantic acceptance, safety acceptance, population false-positive control or authorization. This deliberate omission keeps one implementable hypothesis and leaves a concrete possible failure mechanism visible.
