# Stable-instance amendment: E3-CD1 coarse-content descriptor

Prospective design, 2026-10-14. This is one new, falsifiable descriptor hypothesis, not a reinterpretation of E3-DV1's failed gate. The unmodified instance word's exact-transport ceiling was clean 6/6, SD1.5 VAE 3/6, SDXL VAE 6/6, T3 .2 6/18 (one source majority), and .4 4/18 (two majorities). Those failures remain. No new experiment was performed for this amendment.

## Decision and changed task

Test **only the existing coarse DCT component**, using new fixed public projections, before any dual-carrier implementation. Call its 32-bit descriptor h_CD and the eventual candidate E3-CD1. It represents coarse spatial appearance; it is not a promise to identify every pixel instance or distinguish texture-only siblings. Regeneration can discard the detail that distinguishes those siblings. A method cannot recover destroyed distinguishing information merely by transmitting a stable original label: the suspect-side content comparison still needs that information.

This deliberately isolates the observed bottleneck. E3's present descriptor allocates up to 75% of feature energy to local gradients. Remove that term completely instead of tuning a mixing coefficient on six regeneration sources. Keep the existing coarse frequency weighting, preprocessing and dimensions. This is preferable for the first diagnostic to a newly fitted VAE descriptor because it needs no additional learned representation, GPU inference, training data or carrier-dependent features. VAE features can also drift with regeneration and can be pulled by their own carrier; they are not automatically an instance identity.

Stability alone cannot advance this candidate. It must preserve measured impostor discrimination, including cheap texture-sibling controls. If it fails those controls, record that coarse-content consistency may remain useful, but **do not implement the dual carrier under this protocol** or rename the failure as successful instance binding. This makes the tradeoff visible rather than assuming a smoother descriptor is a repair.

## Exact descriptor, fixed before values are inspected

Use the native E3 RGB-to-luma preparation and native v4 block analysis to obtain block means. Area-resample those means to the existing 32 by 32 HASH_GRID. For all 63 non-DC frequencies (u,v) in 0..7 by 0..7, in existing _HASH_BAND order, compute the existing orthonormal DCT coefficient and multiply by hypot(u,v), exactly as revised_watermark_v4._perceptual_hash lines 501-507. Normalize this 63-vector to unit L2 norm. Norm below 1e-9 yields **unavailable**, never a common all-zero identity.

Apply the existing _sign_projections with the resolved public profile key/config and the literal domain label b'E3-CD1-coarse-instance-v1'. Keep its fixed 32 output bits, stream construction, bit order and 1e-9 sign convention. There is exactly one projection stream. No seed search, owner search, whitening learned from the panel, bit selection, median threshold fitting, hash retries or appended gradient feature is permitted. Keep radius 6 and mismatch distance 10: 0..6 match, 7..9 uncertain, 10..32 mismatch. Store continuous vectors and signed projection margins as diagnostics, not alternate acceptance rules.

Set h_CD targets from each **canonical unmarked RGB source**, not its best-performing marked output. This is a new target convention and must be reported alongside old E3's operational target convention. Native q and all its actual checks stay unchanged. For the eventual writer, calculate h_CD once from the canonical source and never retarget after optimization.

## Capacity and chance calculations

The descriptor transmits 32 bits but those bits need not have 32 bits of empirical entropy. Under an **ideal independent uniform 32-bit impostor word**, a radius-six ball contains sum(k=0..6) C(32,k)=1,149,017 words. Its probability is 1,149,017/2^32 = approximately 0.000267526, corresponding to about 11.87 bits of rejection information. The union bound for 552 tested comparisons would be approximately 0.1477 under that hypothetical marginal model; ordered duplication does not increase independent evidence. Zero finite-panel collisions is therefore an observation, not a rare-event population FPR certificate.

Neither the uniform null nor independent bits is established here. Natural images share structure, q-nearest pairs are selected for similarity, and the projection seed is public. An adaptive writer may choose content or construct the public mark. No cryptographic authorization or forgery resistance follows. For truly isotropic random hyperplanes, mismatch probability is angle/pi; the implementation uses Rademacher projections, so that identity is **not an exact theorem for this implementation**. Report angles/margins empirically without converting them to guaranteed probabilities. BCH(59,32,t=5) corrects transport corruption; it does not add descriptor information or fix content collisions.
