## Exact V1 algorithm

1. Let x0 be the received RGB8 image. In inference mode, construct x1 = R(x0), x2 = R(x1). R is exactly the existing `reconstruct(..., 'sd15_vae')` image operation: normalize RGB8, posterior **mode** encode, unscaled VAE decode, clamp, round to RGB8 by the same implementation, and reload/use that RGB8 result. No posterior sampling, diffusion, safety filtering, resize, gradient, test-source image, or target payload enters R. Reuse an encoding only when it is literally the same pinned operation on the same RGB8 values. This is detector preprocessing, not another attack.
2. Obtain the 320-chip vector p(v) from the existing SD1.5 encoder and `Layout.projections` for each xv, v=0,1,2. For every segment j and bit b compute a(v,j,b) = dot(p(v)[10j:10j+10], table[j][b]). Use the complete existing owner table; do not learn a table from twelve payloads.
3. Obtain native q0 by the current `_key_test` on p(0), including its existing q_now tie rule. For each view compute normalized gap d(v,j) = [a(v,j,1)-a(v,j,0)] / ||p(v)||. A zero norm yields zero gaps. Set qV[j] to 1 when median(d(0,j),d(1,j),d(2,j)) > 0, to 0 when it is < 0, and to q0[j] when it is exactly zero. This is a fixed per-bit majority with a deterministic tie. No threshold on gap size, confidence-weight fitting, or source-specific choice is permitted.
4. Compute **selected original-view score** A0(qV) = sum_j a(0,j,qV[j]) / ||p(0)||; define zero-energy score as zero. Compute the ordinary original-view recomputed q_now score unchanged. Pass `_channel_result` a test with `code=qV`, `decoded=A0(qV)`, and `recomputed=A0(q_now)`. Thus V1 readable q requires A0(qV) >= **8.259326826136963**. The recomputed-only threshold remains **4.982033056390042**. If qV does not pass the searched threshold, retain only the existing recomputed-only presence path; do not try q0 as a second readable candidate.
5. Apply the existing soft content rule to the selected q and the **original suspect's** CLIP features. Route the one instance extraction exactly as RC1: qV when semantic.read is true, otherwise q_now. Preserve the existing h extraction, original suspect-derived h comparison and decision table. ## Capacity, false positives and side information

V1 carries the same 32-bit q through 320 semantic chips and the same operational 32-bit h through its existing tier. Its message space is still 2^32; the three views add **zero transmitted bits** and are deterministically dependent observations. There is no Shannon-capacity estimate, independent-repetition gain, ECC correction radius, or promise of correcting two errors. Under a hypothetical independent equal-error model a majority would have error 3e^2-2e^3; that model is not used for thresholds, power, or expected recovery here.

For every fixed original p(0), A0(qV) <= max_q A0(q), and the original separable decoder computes that maximum exactly over all 2^32 q. Therefore V1's **semantic readable-presence event** is a subset of the old original-view searched-presence event, regardless of how the two extra views select q. Including the unchanged recomputed-only presence branch retains this set inclusion for semantic found. There is no extra factor of three in this particular original-view semantic-presence union: only one of the original 2^32 patterns is verified. This is a deterministic containment argument, not a population FPR estimate.

The original nominal random-sign bound still needs its null assumptions and does not certify public-image/adaptive-attacker behavior. Content-match and any-channel acceptance do **not** inherit the simple containment: selecting a different q changes content agreement and the instance codebook route. Even one routed instance call is data-selected; a conservative hypothetical enumeration can include 2^32 q routes times 2^32 h patterns, and dependence/public construction remain unresolved. Do not publish a new FPR number from the old fields. Require zero observed any-channel detections in the complete declared negatives, with exact denominators and repeated-source correlation disclosed. Fresh calibration is later work only after an eligible survivor exists.

Detector side information is still suspect pixels, claimed public OwnerID, fixed profile, pinned SD1.5 VAE and CLIP weights. There is no inversion, source image, source q, per-source codebook, private key or SDXL detector model. V1 costs three carrier observations and two VAE decodes, so its speed must be measured and reported; “lightweight” is not established by naming it so. The original content predicate is not used to manufacture a selected matching payload. Nevertheless public embedding remains an ownership-authorization counterexample, and T4/T5 preservation must be measured after the eligibility screen.
