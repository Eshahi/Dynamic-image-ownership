## Exact stationary shortcut

Permit skipping the remaining physical gradient iterations **only when every active branch's loss is exactly zero and every individual hinge is inactive** at the same current state, with finite forward values and a feasible, fixed-point projection state. Explicitly check `9-s <= 0` and all `1-g_j <= 0`; a squared loss can underflow to zero despite a small positive hinge, so loss equality alone is insufficient. This is not tolerance-based early stopping: a positive hinge, however small, cannot trigger it. Do not infer the condition from only the selected worst branch unless all branch losses and hinges were actually evaluated for that iteration.

The loss is a sum of squared ReLU hinges. Each zero hinge has zero derivative, including its boundary under the implemented ReLU derivative. Thus if every branch loss is zero, all branch gradients are zero, as is the chosen subgradient of their maximum. Normalized descent `delta -= lr * gradient / (norm(gradient) + 1e-12)` then makes exactly no update. The declared optimizer has no momentum, weight decay, injected noise, stochastic transforms or evolving targets. Its later learning-rate change cannot move a zero-gradient state. Forward RGB8 straight-through quantization does not change this conclusion because the upstream loss derivative is zero.

Projection is the remaining qualification. Repeated projections must leave this stored state unchanged: RGB bounds and both L2 constraints must already be satisfied, and the actual projection routine must make no further change when called once on the state. Check equality of the projected tensor with the stored tensor using the routine's exact tensor comparison, not an approximate feasibility tolerance. If it changes, retain the projected state and execute normally; do not shortcut on the old state's zero loss. This prevents a numerical projection drift from invalidating the stationarity claim. The initial zero delta must meet the same condition before skipping an entire refinement.
