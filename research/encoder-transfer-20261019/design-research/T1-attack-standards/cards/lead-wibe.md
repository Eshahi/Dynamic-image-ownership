# WIBE software and WARP paper linkage

[WARP primary abstract](https://arxiv.org/abs/2609.40031) explicitly links its code to [ispras/wibe](https://github.com/ispras/wibe). WIBE is the software release for the counted [WARP paper](warp.md), not a second benchmark paper. Repository discovery and README inspection provide release context, not an independent V2 source count.
