# SD1.5 implementation audit (V2)

Inspected 2026-10-20. Documentary source audit; no package import, model loading or inference. Source aliases resolve to exact official file URLs and cached SHA-256 records in `source-manifest-1b.json`.

R0 is the retained image-to-image comparator at RGB512. Model: `stable-diffusion-v1-5/stable-diffusion-v1-5@451f4fe16113bff5a5d2269ed5ad43b0592e9a14`; official fp16 variant, diffusers **0.35.1**. The repository's `model_index.json` names text-to-image `StableDiffusionPipeline`; the explicitly selected compatible API is `StableDiffusionImg2ImgPipeline`, not that default class. No training-lineage independence from SD1.x is claimed.
