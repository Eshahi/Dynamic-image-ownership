# TrustMark-Q proposed native implementation audit (V2)

Inspected 2026-10-20. Documentary source audit; no package import, model loading or inference. Source aliases resolve to exact official file URLs and cached SHA-256 records in `source-manifest-1b.json`.

P1 remains proposed only. Pin official `adobe/trustmark@6df5a0a29b51cbec832695fdf02051a1937e37bd`, Python API `TrustMark(model_type="Q", use_ECC=True, encoding_type=BCH_5)`. Native binary payload capacity is61bits, encoded to100 neural bits. Do not use an unofficial Hub mirror, JS/WASM implementation or the paper's generic256 decode description as a replacement for this pinned Python path.
