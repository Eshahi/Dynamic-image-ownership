# Retained scientific result audit

`scripts/m1_scientific_result_audit.py` provides CPU artifact checking for the new scientific collector. It does not issue authority, open original raw sources, load a model, accept a gate or establish recovery lineage. The collector must first validate the run/core identity, planned inventory and all predecessor receipts. Integration with that complete collector is still pending.

For an already retained candidate image, it verifies contained nonlinked PNG/NumPy files against exact byte hashes and sizes, the saved RGB512 pixel hash, finite512-dimensional E and16384-dimensional z observations,32-bit H, query-to-image joins, and exact re-execution of the public float64 score/denominator/state algebra. PSNR and SSIM are independently recomputed from saved source/suspect pixels using the frozen metric implementation. LPIPS, CLIP, VAE and safety outputs remain retained model observations; the audit does not claim independent model inference. Invalid or missing artifacts must become adverse missing observations in downstream summaries, never favorable negative calls.

Twelve synthetic CPU tests passed (4.982 seconds): artifact and score replay, adversarial changes to bytes/scores/joins/quality/safety, nonfinite observations, enrollment control reconstruction and the exact RGB8 cap, and real v5 codec replay including rejection of a changed decision. Enrollment residuals are recomputed in the original float32 subtraction order. V5 uses its separately retained exact comparator semantic input, not the candidate reader's additional float64 normalization; all codec fields except nondeterministic timing are compared. These establish artifact/algebra behavior, not scientific performance. Full run/recovery collection and checkpoint lineage integration remain separate obligations.
