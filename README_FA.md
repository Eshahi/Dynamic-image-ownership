# راهنمای نسخه آفلاین

فایل THESIS_GUIDE_OFFLINE.html را از ZIP خارج کنید و با Chrome، Edge، Firefox یا Safari به‌روز باز کنید. اینترنت، Python، Node یا Server لازم نیست. Preview پیام‌رسان ممکن است JavaScript را اجرا نکند؛ فایل را دانلود و در مرورگر باز کنید.

تمام ۵۸ Task و اصلاحات academic-agent-v5، جست‌وجو، جزئیات Task، Copy Agent Brief، دانلود Agent Plan، یادداشت‌ها، تیک‌ها و Import/Export Progress موجودند. منابع اینترنتی در فایل دانلود نشده‌اند. اصل پروپوزال و نتایج آزمایش داخل این بسته نیستند.

یادداشت‌ها و تیک‌ها داخل مرورگر هر گیرنده‌اند و با ارسال HTML منتقل نمی‌شوند. برای انتقال یا Backup از Export Progress استفاده کنید. Import فقط با تأیید شما داده فعلی را جایگزین می‌کند. اگر ذخیره محلی مسدود باشد هشدار نمایش داده می‌شود؛ قبل از بستن Export بگیرید.

برای ارسال یک فایل کافی است HTML را بفرستید؛ ZIP برای پیام‌رسان‌هایی است که HTML را نمی‌پذیرند. فایل هیچ اطلاعات شخصی ذخیره‌شده، Credential یا نتیجه آزمایش ندارد.

این برنامه، شواهد موفقیت روش یا تأیید دانشگاه نیست.
